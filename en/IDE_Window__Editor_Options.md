IDE Options - Editor

This is part of the online help for the IDE. 

It describes the section: "Editor Options". You can open the described dialog in your IDE via: 

  * The menu: "Tools" => "Options" / Editor options ...
  * The source-editor pop-up menu: "Editor properties ...



The available editor options are: 

  * [General](<IDE_Window__Editor_Options_General.md> "IDE Window: Editor Options General")
    * Undo / Redo
    * Scrolling
    * Indent and Tabs  
Please also see Codetools for automatic indent of Pascal sources
    * Cursor
    * Selection
    * [Misc](<IDE_Window__Editor_Options_General_Misc.md> "IDE Window: Editor Options General Misc")
      * Showing Whitespace
      * Trimming spaces
      * Copy/paste: unselected / fold
      * Search
  * [Display](<IDE_Window__Editor_Options_Display.md> "IDE Window: Editor Options Display")
    * [Gutter / Margin](<IDE_Window__Editor_Options_Display_Gutter.md> "IDE Window: Editor Options Display Gutter")
    * Font
    * Line-spacing
    * [Colors](<IDE_Window__Editor_Options_HighlightColors.md> "IDE Window: Editor Options HighlightColors")
      * Highlighting Pascal/Language specific elements
      * General Highlighting (Selection, Line Highlights, ...)
    * [Markup and Matches](<IDE_Window__Editor_Options_Markup.md> "IDE Window: Editor Options Markup")
      * Highlight other occurrences of the current word
      * Matching brackets
      * Extended Pascal-Keyword settings
  * [User defined markup](<IDE_Window__Editor_User_Defined_Words.md> "IDE Window: Editor User Defined Words")
  * Highlight your own chosen words 
    * [Key Mappings](<IDE_Window__Editor_Options_Keymap.md> "IDE Window: Editor Options Keymap")
      * Keyboard
      * See [Lazarus IDE Shortcuts](<Lazarus_IDE_Shortcuts.md> "Lazarus IDE Shortcuts").
    * [Mouse settings](<IDE_Window__Editor_Options_Mouse.md> "IDE Window: Editor Options Mouse")
      * Mouse
  * [Completion and Hints](<IDE_Window__Editor_Options_Completion_Hints.md> "IDE Window: Editor Options Completion Hints")
    * Automatic removal of unused events
    * Automatic completion of Pascal blocks (begin/end)
    * Automatic completion of identifiers
    * Hints in the Editor
  * [Code Folding](<IDE_Window__Editor_Options_Code_Folding.md> "IDE Window: Editor Options Code Folding")
    * Source/Text folding
  * [Divider Drawing](<IDE_Window__Divider_Drawing_Divider_Draw.md> "IDE Window: Divider Drawing Divider Draw")
    * Drawing divider lines
  * [Pages and Windows](<IDE_Window__Editor_Options_MultiWindow.md> "IDE Window: Editor Options MultiWindow")
    * Notebook and its tabs
    * Automatic selection of windows for code navigation
