# amunits

The Amigalib package provides pascal units and includes for interfacing with the Classic Amiga Operating System (version 2.04 or later). 

Documentation for these interfaces (C version) can be found in the Amiga Rom Kernal Reference Manual 3th Edition: Includes & Autodocs book (The Amiga Classic developer CD also contains this documentation).
