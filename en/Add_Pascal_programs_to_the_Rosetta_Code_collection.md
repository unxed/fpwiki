# Add Pascal programs to the Rosetta Code collection

## About

The Rosetta Code page shows a large number of programming tasks and solutions in many programming languages. See their [home page](<http://rosettacode.org/wiki/Main_Page>) for more details. 

## Goals

Our goals are to have Pascal examples for as many tasks as possible and present the advantages of Pascal. 

  * Add more Pascal examples.   
At present, there are about 200 examples out of 600 tasks.   
Open tasks are listed here: <http://rosettacode.org/wiki/Reports:Tasks_not_implemented_in_Pascal>


  * Improve present examples.  
This is the list of Pascal examples: <http://rosettacode.org/wiki/Category:Pascal>



## Related

See [Rosetta_Stone](<Rosetta_Stone.md> "Rosetta Stone"), our own Rosetta Stone page for a mapping between operating system tasks and FreePascal/Lazarus ways to perform those.
