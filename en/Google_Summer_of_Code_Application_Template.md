# Google Summer of Code Application Template

Note: This page is a template to be utilized in case we are accepted to participate in the Google Summer of Code by applying students 

1 - Name, Address, E-Mail and other contact information 

2 - Why would you like to participate in this project? 

3 - How would you describe your programming skills? Have you utilized before a version control system? 

4 - Have you ever contributed to an open source project? Do you plan on contributing further after the project finishes?
