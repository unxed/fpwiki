# Template Engines

This page lists template engines for generating text or HTML. 

project | license | notes   
---|---|---  
[adp2html](<http://svn.freepascal.org/cgi-bin/viewvc.cgi/adp2html.pp?view=markup&revision=757&root=fpchtml>) | FPC?  | Tool used to generate the FPC website. (undocumented?)   
fptemplate  | FPC  | Part of fcl-web. (undocumented?)   
[QTemplate](<https://github.com/leledumbo/QTemplate>) | Public Domain  | This unit implements an alternative to FPTemplate engine, with different approach.   
[JTemplate](<https://github.com/risoflora/brookfreepascal/tree/master/plugins/jtemplate>) | FPC  | This plugin helps you to fill variables in a template file.   
[DVDChief Template Engine](<http://dvdchief.com/delphi/>) | LGPL or MPL  | Delphi XE/XE2/XE3 compiled to native code. Has functions and expressions, Smarty-like syntax.   
[Web Application Template Engine](<Web_Application_Template_Engine.md> "Web Application Template Engine") | ?  | Stub wiki page, with broken link (as of Jan 2014).   
[FastTrac Template Engine](<https://sourceforge.net/projects/ftopf/>) | MPL  | Delphi encapsulation of the Smarty template engine.   
[Synopse Mustache Template Engine](<http://blog.synopse.info/?tag/Mustache>) | MPL or GPL or LGPL  | Free Pascal / Delphi encapsulation of the Mustache template engine.   
[mustapas](<https://github.com/leledumbo/mustapas>) | MIT  | Simple Mustache template engine in Free Pascal.   
[STE](<https://github.com/sash-rc/ste>) | Public domain  | Simple Template Engine (vars, if/else, for, datasets).   
[Kumis](<https://github.com/TandangDewe/kumis>) | FPC  | Simple, Mustache-like, template engine implemented in Free Pascal.   
[SimpleTPL](<https://github.com/michalgw/SimpleTpl>) | LGPL-2.1  | Simple template engine.   
[Template Engine](<https://github.com/Fr0sT-Brutal/TemplateEngine>) | MPL-2.0  | The DVD Chief template engine used in generation of movie and person template and HTML export. Engine has most features of Smarty PHP template engine.   
[dmustache](<https://github.com/synopse/dmustache>) | Not Mentioned  | SynMustache is a Delphi/FPC implementation of the [Mustache template language](<http://mustache.github.io>).   
[ooTemplateParser](<https://github.com/VencejoSoftware/ooTemplateParser>) | [Modified BSD License (BSD)](<https://github.com/VencejoSoftware/ooTemplateParser/blob/master/license.md>) | Code to use text templates in Pascal code.   
[Maki](<https://github.com/soerensen3/maki>) | Not Mentioned  | Maki is a templating engine for Free Pascal based on nodes (aka graphs).
