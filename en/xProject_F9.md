# xProject F9

[![FacebookFrontpage-small.png](https://wiki.freepascal.org/images/4/40/FacebookFrontpage-small.png)](</File:FacebookFrontpage-small.png>)

  
... enables the easy conversion of your Delphi or Lazarus applications into fully functional web applications with just one click. 

The compiler takes the source code and GUI settings and generates a web application from it that looks and functions exactly like the original program. 

Exclusively HTML, CSS, and Javascript code will be the result. 

  
[xProject F9 is free for open source projects](<https://green-hill.srl>)
