# Not equal

│ **English (en)** │  **[русский (ru)](<../ru/Not_equal.md>)** │

<>

The not equal bigramm `<>` (consisting of [`<`, the less than symbol](<Less_than.md> "Less than"), followed by [`>`, the greater than symbol](<Greater_than.md> "Greater than")) is used to compare two values. The binary operator evaluates to [`true`](<false_and_true.md> "false and true"), if both values differ from each other. 

## implicit definition

Note, when the [equal operator](<Equal.md> "Equal") has been overloaded for a custom type, but unequal does not have its own (explicit) definition, [FPC](<FPC.md> "FPC") will assume `x <> y` is the same as `not (x = y)`.
