# IDE Documentation Roadmap

## Introduction

This page is intended to keep track of the progress of the IDE documentation. If you want to participate in the documentation, edit this page and put you name after the item named in the table below. Then fire up [Lazarus Context Help Editor](</index.php?title=Lazarus_Context_Help_Editor&action=edit&redlink=1> "Lazarus Context Help Editor \(page does not exist\)") and start documenting. When you are finished submit your work be creating and submitting a [patch](<Creating_A_Patch.md> "Creating A Patch")!
