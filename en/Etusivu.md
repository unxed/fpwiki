# Tervetuloa Lazarus ja FreePascal Wikiin

## Yleistä

Tämän wikin päämääränä on tietämyksen lisääminen FreePascal'ista, Lazarus'ista ja sukulaisprojekteista. FreePascalista on hyvä käyttäjän dokumentointi useilla eri formaateilla (englanniksi). FreePascalin kehittäjien informaatiota, organisointiasioita ja aiheita ei vielä ole kunnollisesti dokumentoitu ja niitä on kerätty tähän Wikiin. Toisaalta kun Lazarusissa on puutteita käyttäjän dokumentoinnissa niin tässä on paikka avoimelle dokumentoinnille (siis Wiki) missä jokainen voi muokata ja lisätä sisältöä. 

Wiki nopeuttaa näitä asioita. Se mahdollistaa muutoksien ja lisäysten tekemisen www-selaimella. Tämä on siis Wiki jota kuka tahansa voi muokata ja lisätä tietoa. Suomenkieliset ohjeet Wikin käyttöön löydät [Wikipedian ohjesivuilta](<http://fi.wikipedia.org/wiki/Wikipedia:Ohje>). Harjoittelua varten on oma [hiekkalaatikko eli Sand Box](<Sand_Box.md> "Sand Box"). 

Jos huomaat jotain epäselvyyksiä tai ongelmia, niin ota yhteyttä sivun [administraattoriin](<http://sourceforge.net/users/vlx/>) tai lähetä virheraportti [Lazarus-CCR](<http://sourceforge.net/projects/lazarus-ccr>) SF paikan kautta. Lisäksi voit lähettää palautetta [Site Feedback](<Site_Feedback.md> "Site Feedback") sivun kautta.

## Tiedostojen imurointi

  * Kaikki saatavissa oleva komponentit ja paketit löytyvät [Lazarus-CCR Sourceforge](<http://sourceforge.net/project/showfiles.php?group_id=92177>) tiedostoalueelta.
  * Free Pascal Compiler ja Lazaruksen (yhä beeta asteella) useille eri käyttöjärjestelmille tarkoitetut versiot löytyvät [The Lazarus Sourceforge](<http://sourceforge.net/project/showfiles.php?group_id=89339>) paikasta.
  * Lisää dokumentaatiota löytyy [Components and Code examples](<Components_and_Code_examples.md> "Components and Code examples") wikistä.
  * [Free Pascal Compiler tiedostojen imurointi ja peilipalvelimet](<http://www.freepascal.org/sdown.html>)
  * [Lazarus IDE www-sivu](<http://lazarus.freepascal.org>).
  * Lazaruksen päivittäiset versiot löytyvät Lazarus Snapshots Downloads/fi-sivuilta (Joskus tarjolla saattaa olla aika testaamatonkin versio).

## Muut asiat

### Lazarus IDE

Uutiset ja viimeisimmät tiedot Lazarus kehitysympäristön tilasta löydät [Lazarus IDE www-sivuilta](<http://lazarus.freepascal.org>). Julkaistut Lazarus IDE ja FreePascal compiler voit hakea sieltä. Myös sourceforge.net [Lazarus file area](<http://sourceforge.net/project/showfiles.php?group_id=89339>):lta löytyy viimeisin julkaistu kääntäjä ja kehitysympäristö. 

#### Lazarus-projektit

Listamme projekteista jotka käyttävät Lazarusta ja ovat yleisesti saatavilla löytyy "[Projects using Lazarus](<Projects_using_Lazarus.md> "Projects using Lazarus")"-sivulta. 

#### Linkkikokoelmat

Keräämämme Delphi/Kylix www-sivuja löytyy "[Page Of Code Sites](<Page_Of_Code_Sites.md> "Page Of Code Sites")"-sivuilta. Jos tiedät hyvän, tähän ryhmään sopivan, linkin jota ei vielä löydy sivulta niin voisitko ystävällisesti lisätä sen sinne. 

#### Erikoistuneet hakukoneet

Jos tarvitset pieniä vinkkejä avuksesi, oppiaksesi tai ratkaistaksesi jonkun ongelman niin voit hyödyntää näitäkin. Tamarack Associates operoi nopeaa [hakukonetta](<http://www.tamaracka.com/search.htm>) joka on erikoistunut Borland usenet ryhmään. Mer Systems Inc:ltä löytyy santapainen [hakukone](<http://www.mers.com/searchsite.html>). Merkittävä määrä tietoa löytyy käyttämällä Earl F. Glynn's Computer Lab:n [hakukonetta](<http://www.efg2.com/Lab/search.htm>) tai [kirjastoa](<http://www.efg2.com/>).

[Lazarus käyttäjien](<Marketing_Case_Studies.md> "Marketing Case Studies") selityksiä miksi Lazarus IDE on sopiva.
