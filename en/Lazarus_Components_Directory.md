# Lazarus Components Directory

│ **English (en)** │

The "components" directory of the Lazarus source tree comes with a number of very useful components, and they are described below. Note that there are also other components which can be downloaded separately from the [Lazarus Code and Component Repository](<Components_and_Code_examples.md> "Components and Code examples"). 

## List of Components

  * aggpas
  * cgi
  * [chmhelp](<chmhelp.md> "chmhelp") \- Provides context-sensitive help for the IDE using CHM files.
  * codetools
  * compilers
  * custom
  * [customdrawn](<Lazarus_Custom_Drawn_Package.md> "Lazarus Custom Drawn Package") \- An under construction package containing all kinds of custom drawn components for Lazarus.
  * customform
  * [daemon](<Daemons_and_Services.md> "Daemons and Services") \- Creating background applications
  * datadict
  * [datetimectrls](<DateTimeCtrls_Package.md> "DateTimeCtrls Package") \- This package contains [TDateTimePicker](<DateTimeCtrls_Package.md> "DateTimeCtrls Package") control and [TDBDateTimePicker](<DateTimeCtrls_Package.md> "DateTimeCtrls Package") (a data aware version of TDateTimePicker).
  * dbexport - Components that allow exporting datasets to RTF, simple XML, TeX, DBF, JSON, SQL statements, fixed format text files, CSV files, and more formats: 
    * includes/see [fpXMLXSDExport](<fpXMLXSDExport.md> "fpXMLXSDExport"): other XML formats (Delphi clientdataset format, Excel, MS Access, and ADO.Net)
    * includes/see [fpdbfexport](<fpdbfexport.md> "fpdbfexport"): export to DBF/(Visual) FoxPro formats
  * editortoolbar
  * [education](<Lazarus_for_education.md> "Lazarus for education") \- How to setup the IDE for courses and beginners
  * externhelp
  * filebrowser
  * fpcunit - unit testing support. See also [fpcunit](<fpcunit.md> "fpcunit")
  * [fpweb](<fcl-web.md> "fcl-web") \- Creating web applications with the fpWeb framework, which allows to use a same source to deploy a web application as CGI, FastCGI or as an Apache Module
  * [fractions](<Fractions.md> "Fractions"): A unit for doing arithmatics with fractions
  * h2pas
  * images
  * industrial - Components that emulate industrial controls/plant controls like LEDs, arrows etc. Present since at least Lazarus 1.2.0
  * jcf2
  * [lazcontrols](<LazControls.md> "LazControls")
  * lazreport
  * lazsvnpkg
  * lazthread
  * [leakview](<leakview.md> "leakview")
  * macfiles
  * memds - A simple in-memory dataset; see also [How to write in-memory database applications in Lazarus/FPC](<How_to_write_in-memory_database_applications_in_Lazarus/FPC.md> "How to write in-memory database applications in Lazarus/FPC")
  * messagecomposer
  * mouseandkeyinput
  * mpaslex
  * [opengl](<OpenGL.md> "OpenGL") \- A windowed-control which provides an OpenGL surface
  * paradox - Database support for Paradox files.
  * plotfunction
  * prettyformat
  * prettymessages
  * printers
  * projecttemplates
  * rtticontrols
  * rx
  * sdf - CSV (delimited text) dataset support
  * simpleideintf
  * sqldb - SQL database support
  * sqlite
  * [synedit](<SynEdit.md> "SynEdit") \- SynEdit is an advanced multi-line edit control, which is integrated into the Lazarus.
  * synunihighlighter
  * [tachart](<TAChart.md> "TAChart") \- charting component
  * tdbf - Database support for DBase/Foxpro/Visual Foxpro .dbf files. See also [Lazarus_Tdbf_Tutorial](<Lazarus_Tdbf_Tutorial.md> "Lazarus Tdbf Tutorial")
  * todolist
  * turbopower_ipro
