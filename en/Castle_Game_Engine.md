[Castle Game Engine](<https://castle-engine.io/>) is a cross-platform 3D and 2D [game engine](<Game_Engine.md> "Game Engine"). 

  * You can use any 3D or 2D software to create models in various formats: [glTF, X3D, VRML, Spine JSON, Collada...](<https://castle-engine.io/creating_data_model_formats.php>). In particular creating game models in [Blender](<https://castle-engine.io/creating_data_blender.php>) is fully supported, through the glTF format.


  * The engine can be used to compile desktop (Linux, Windows, macOS), mobile (Android, iOS) and consoles ([Nintendo Switch](<https://github.com/castle-engine/castle-engine/wiki/Nintendo-Switch>)) games.


  * You can [design and build applications in a visual editor](<https://castle-engine.io/manual_editor.php>). The editor utilizes a [command-line build tool under the hood](<https://github.com/castle-engine/castle-engine/wiki/Build-Tool>). The build tool calls FPC and some other tools to compile and run the project.


  * Many graphic effects are available: physically-based rendering, shadows, mirrors, bump mapping, shader effects, gamma correction. Rendering is done through OpenGL or OpenGLES.


  * Numerous services, like in-app purchases and game services, are available on mobile devices. See [Android servcies](<https://github.com/castle-engine/castle-engine/wiki/Android-Services>), [iOS services](<https://github.com/castle-engine/castle-engine/wiki/iOS-Services>).


  * The user interface is cross-platform and supports anchors and automatic scaling.



The engine is open-source. [The engine may be used under GNU LGPL with "static linking exception"](<https://castle-engine.io/license.php>), just like FPC RTL and Lazarus LCL. So you can make both open- and closed-source games.
