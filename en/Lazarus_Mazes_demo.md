# Lazarus Mazes demo

## About

The [Lazarus Mazes](<https://github.com/eny-fpc/lazes>) program illustrated below is a demonstration of how you can use Lazarus to create a maze. The maze generation is based on a [depth-first backtracking](<http://en.wikipedia.org/wiki/Maze_generation_algorithm#Depth-first_search>) algorithm. As a bonus, a simple maze solver is also implemented that shows a route from the start of the maze to the exit.
