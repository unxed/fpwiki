Portal:Game Development

Pascal was used to make games since its creation, including some well-known classic games like Apogee's [Beyond the Titanic](<https://en.wikipedia.org/wiki/List_of_minor_Apogee_Software_video_games#Beyond_the_Titanic>). Today Pascal is still used to create games by both amateur and professional game-makers.
