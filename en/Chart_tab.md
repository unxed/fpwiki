# Chart tab

│ **English (en)** │  **[русский (ru)](<../ru/Chart_tab.md>)** │

The **Chart tab** of the [Component Palette](<Component_Palette.md> "Component Palette") lists visible components of the [Lazarus Component Library](<LCL.md> "LCL") for use with graphs and charts from the [TAChart](<TAChart.md> "TAChart") package. 

[![Component Palette Chart.png](https://wiki.freepascal.org/images/2/29/Component_Palette_Chart.png)](</File:Component_Palette_Chart.png>)

---|---|---  
[![tchart.png](https://wiki.freepascal.org/images/2/23/tchart.png)](</File:tchart.png>) | [TChart](<TChart.md> "TChart") | Draws various kind of graphs and charts on screen   
[![tlistchartsource.png](https://wiki.freepascal.org/images/4/44/tlistchartsource.png)](</File:tlistchartsource.png>) | [TListChartSource](<TAChart_documentation.md> "TAChart documentation") | Chart source storing series data in an internal list   
[![trandomchartsource.png](https://wiki.freepascal.org/images/8/8e/trandomchartsource.png)](</File:trandomchartsource.png>) | [TRandomChartSource](<TAChart_documentation.md> "TAChart documentation") | Chart source with random data for chart layout optimization at design-time   
[![tuserdefinedchartsource.png](https://wiki.freepascal.org/images/7/7f/tuserdefinedchartsource.png)](</File:tuserdefinedchartsource.png>) | [TUserDefinedChartSource](<TAChart_documentation.md> "TAChart documentation") | Chart source providing an interface between series and user-defined data structures
