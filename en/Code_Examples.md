## Default components provided by Lazarus

The rest of this page covers components not delivered with Lazarus. For the default components provided with Lazarus, please see [Lazarus Components Directory](<Lazarus_Components_Directory.md> "Lazarus Components Directory"). 

As Lazarus uses the FPC compiler, you can also use packages provided by FPC. See [Package List](<Package_List.md> "Package List").

### Lazarus-CCR archiving

  * [FreePascalArchivePackage](<FreePascalArchivePackage.md> "FreePascalArchivePackage") \- Conversion of TurboPower Software's Abbrevia library for Free Pascal.



### Lazarus-CCR file formats

  * [FPExif](</index.php?title=FPExif&action=edit&redlink=1> "FPExif \(page does not exist\)") \- Library for reading/writing EXIF metadata to image files (jpeg, tiff).
  * [FPSpreadsheet](<FPSpreadsheet.md> "FPSpreadsheet") \- A library for handling spreadsheet files. Supports the formats from MS Excel (XLS, XLSX, Excel XML) and OpenOffice. It also supports these file types: CSV, HTML, Wikitables.
  * [fpvectorial - Text Document Support](<fpvectorial_-_Text_Document_Support.md> "fpvectorial - Text Document Support") \- A library for handling text document files. Currently supports exporting to .docx and .odt file formats only.



### Lazarus-CCR tools

  * [ExtraSyn](</index.php?title=ExtraSyn&action=edit&redlink=1> "ExtraSyn \(page does not exist\)") \- Additional highlighters for TSynEdit.
  * [GridPrinter](<GridPrinter.md> "GridPrinter") \- Component to simplify printing of grids. Includes a preview component.
  * [LazBarcodes](<LazBarcodes.md> "LazBarcodes") \- Generate barcodes (QRCode, Aztec, DataMatrix etc).
  * [OnGuard](<OnGuard.md> "OnGuard") \- A port of Turbo Power OnGuard (software registration, protection, serial numbers etc).



### Lazarus-CCR visual components

  * [CalLite](<CalLite.md> "CalLite") \- Lightweight calendar component
  * [CAPTCHA](<CAPTCHA.md> "CAPTCHA") \- Displays random characters which are colored and rotated and overlayed by colored lines to impede machine detection of the CAPTCHA text.
  * [ChemText](<ChemText.md> "ChemText") \- A label which displays subscripts and superscripts in chemical formulas.
  * [ColorPalette](<ColorPalette.md> "ColorPalette") \- Cross-platform color palette grid with ability to select a color from a palette.
  * [ExCtrls](<ExCtrls.md> "ExCtrls") \- Collection of controls which try to overcome limitations posed by the widgetset. Moreover, some missing controls are added.
  * [Flag component](<Flag_component.md> "Flag component") \- A collection of country flags.
  * [Fshcomp](<Fshcomp.md> "Fshcomp") \- Edit components.
  * [HistoryFiles](<HistoryFiles.md> "HistoryFiles") \- A component for store the recent files list into an .ini file and show the result into a menu.
  * [Industrial](<Industrial.md> "Industrial") \- A set of industrial-themed components (LED indicators, seven-segment display, analog gauges, thermometer gauges, knob, on/off switch, etc).
  * [jujiboutils](<jujiboutils.md> "jujiboutils") \- Set of components to input and validate different kinds of data, floats, dates, etc.
  * [JVCL](<JVCL_Components.md> "JVCL Components") \- Lazarus port of a large fraction of the [Visual Component Library](<https://wiki.delphi-jedi.org/wiki/JVCL_Component_Overview%7CJedi>) for Delphi.
  * [LazMapViewer](<LazMapViewer.md> "LazMapViewer") \- Component for embedding maps obtained from the internet, such as Google maps or OpenStreetView, into a Lazarus form.
  * [LongTimer](<LongTimer.md> "LongTimer") \- Visual component based on TIdleTimer working with long intervals (daily, weekly or monthly).
  * [mbColorLib](<mbColorLib.md> "mbColorLib") \- Comprehensive library with more than 30 components for color selection in several color models (RGB, CYMK, HSV, HSL, CIE-Lab).
  * [Poweredby](<Poweredby.md> "Poweredby") \- Visual drop-in component to show a 'Powered by Lazarus' splash screen for 1 second on TForm.Create to promote Lazarus/FPC.
  * [ScrollText](<ScrollText.md> "ScrollText") \- Visual component that displays up-scrolling text (like a Credits screen).
  * [SpkToolbar](<SpkToolbar.md> "SpkToolbar") \- Ribbon-control like in newer Microsoft Office applications.
  * [TPlaySound](<TPlaySound.md> "TPlaySound") \- Visual component to play WAV files in Windows and Linux.
  * [VisualPlanIt](<Turbopower_Visual_PlanIt.md> "Turbopower Visual PlanIt") \- A set of synchronized, data-aware components for adding time, task, & contact management capabilities to applications. Get that Outlook look & feel without the hassle.

### Multimedia

  * [ACS](<ACS.md> "ACS") \- Audio Component Suite, a collection of components to develop applications for audio playing/recording/processing. Can play wav/ogg/mp3/mp2/wma, can record from any recordable source, ripping and more.

  * [UOS](<https://github.com/fredvs/uos>) \- (United Open-libraries of Sound) unifies the best open-source audio libraries. With uos you can: Listen to mp3, ogg, wav, flac, m4a, opus, cda ... audio files. Deal with 16, 32 integer or float 32 bit resolution. Do internet audio streaming of mp3 and opus files. Record all types of input into wav or ogg file with 16 or 32 bit resolution. Add DSP effects and filters, however many you want and record it. Listen to multiple input and output. Produce sound from built-in synthesizer.
