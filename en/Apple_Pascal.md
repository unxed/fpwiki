# Apple Pascal

│ **English (en)** │  **[français (fr)](</Apple_Pascal/fr> "Apple Pascal/fr")** │    
****

**Apple Pascal** was an implementation of [UCSD Pascal](<UCSD_Pascal.md> "UCSD Pascal") for Apple II computers. The compiler generated code for the UCSD-P virtual machine, which was executed by an interpreter for the 6502 processor written by Mark Allen und Richard Gleaves. 

The first version of Apple Pascal appeared in 1979. It was based on UCSD Pascal II.1. Versions 1.1, 1.2 and 1.3 were released in 1980, 1983 and 1984, respectively. 

Apple Pascal had a minor impact in the Apple II world, but it laid the foundation for the development of [Lisa Pascal](<Lisa_Pascal.md> "Lisa Pascal"), [Clascal](<Clascal.md> "Clascal") and [Mac Pascal](<Mac_Pascal.md> "Mac Pascal"), the first implementations of [Object Pascal](<Object_Pascal.md> "Object Pascal").
