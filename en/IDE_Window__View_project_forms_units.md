# IDE Window: View project forms units

│ **English (en)** │

This dialog comes in two flavours: 

[![Project Units 2 0 10.jpg](https://wiki.freepascal.org/images/f/f8/Project_Units_2_0_10.jpg)](</File:Project_Units_2_0_10.jpg>) [![Project Forms 2 0 10.jpg](https://wiki.freepascal.org/images/8/82/Project_Forms_2_0_10.jpg)](</File:Project_Forms_2_0_10.jpg>)

  * [Main Menu](<Main_menu.md> "Main menu") > [Project](<Main_menu.md> "Main menu") > Units: shows the units of the current project (this is the same list as that which appears in the [Project Inspector](<IDE_Window__Project_Inspector.md> "IDE Window: Project Inspector"))


  * [Main Menu](<Main_menu.md> "Main menu") > [Project](<Main_menu.md> "Main menu") > Forms: shows the forms of the current project. These are all units which have an .lfm file with a streamed component.



Select: 

  * the unit and click OK to open it in the source editor; or
  * the form and click OK to open it in the visual form designer.
