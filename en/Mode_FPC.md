# Mode FPC

│ **English (en)** │  **[русский (ru)](<../ru/Mode_FPC.md>)** │

The `FPC` [compiler compatibility mode](<Compiler_Mode.md> "Compiler Mode") is the default mode of [FPC](<FPC.md> "FPC"). 

[`{$mode objFPC}`](<Mode_ObjFPC.md> "Mode ObjFPC") builds on top of `{$mode FPC}`.
