# Oxygene

**Oxygene** (originally known as Chrome) is a variant of Object Pascal produced by Remobjects Software. Originally designed to target the .NET platform, the Oxygene compiler now can also produce output for the Java Virtual Machine, Apple's Cocoa API, and a Remobjects Windows runtime library that utilizes garbage collection. 

For a period of time Oxygene was marketed by Embarcadero Software, the makers of [Delphi](<Delphi.md> "Delphi"), as part of a product called Prism.
