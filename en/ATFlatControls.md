# ATFlatControls

## About

ATFlatControls is a package of several Lazarus visual components, they are used in the [CudaText](<CudaText.md> "CudaText") project UI. These components have separate Wiki pages: 

  * [ATGauge](<ATGauge.md> "ATGauge")
  * [ATTabs](<ATTabs.md> "ATTabs")
  * [ATGroups](<ATGroups.md> "ATGroups")
  * [ATStatusBar](<ATStatusBar.md> "ATStatusBar")
  * [ATScrollBar](<ATScrollBar.md> "ATScrollBar")
  * [ATButton](<ATButton.md> "ATButton")
  * [ATListbox](<ATListbox.md> "ATListbox")
  * [ATFlatToolbar](<ATFlatToolbar.md> "ATFlatToolbar")
  * [ATLinkLabel](<ATLinkLabel.md> "ATLinkLabel")
