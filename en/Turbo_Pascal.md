Turbo Pascal is a dialect of the [Pascal](<Pascal.md> "Pascal") programming language which was sold by Borland International during the 1980s and 1990s for use with the MS-DOS and later Microsoft Windows [operating systems](<operating_system.md> "operating system"). A few versions (1.0 and 1.1) were also released for Apple's System 6 and System 7 (a.k.a. Mac OS in later versions).It provided an _Integrated Development Environment_ or [IDE](<IDE.md> "IDE"), which combined editor, program [compiler](<Compiler.md> "Compiler") and execution environment for developing, debugging, and compiling Pascal [source code](<Source_code.md> "Source code"). 

It would later provide features such as [conditional compilation](<Conditional_compilation.md> "Conditional compilation") and the ability to separately compile modules using the [unit](<Unit.md> "Unit") directive, and would also implement some of the features which were first implemented years earlier in [UCSD Pascal](<UCSD_Pascal.md> "UCSD Pascal"). 

Beginning with version 5.5 Turbo Pascal introduced support for [OOP](<Glossary.md> "Glossary") by an extended version of the [Object Pascal](<Object_Pascal.md> "Object Pascal") syntax that had been introduced with Apple's [Mac Pascal](<Mac_Pascal.md> "Mac Pascal"). For versions 6.0 and 7.0 of the Turbo Pascal language (and product), a separate Windows version was also released: Turbo Pascal for Windows 1.0 and Turbo Pascal for Windows 1.5. 

Turbo Pascal (and the "professional" product version called [Borland Pascal](<Borland_Pascal.md> "Borland Pascal")) were phased out in the 1990s in favor of [Delphi](<Delphi.md> "Delphi") which had language and library enhancements and was focused on [Microsoft Windows](</index.php?title=Microsoft_Windows&action=edit&redlink=1> "Microsoft Windows \(page does not exist\)") GUI programming. There was briefly a Delphi-equivalent for use on the [Linux](<Linux.md> "Linux") operating system called [Kylix](<Kylix.md> "Kylix"). 

The [FPC](<FPC.md> "FPC") Pascal Compiler provides a high level of compatibility with code written for Turbo Pascal and Borland Pascal, and some degree of compatibility with code written for Delphi and Kylix.
