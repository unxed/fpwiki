# About

_ATScrollBar_ is a scrollbar component for Delphi and Lazarus. It's not replacement for standard control, but is alternative one, it has different API. It paints itself OS-indenendant, using custom drawing on canvas. 

Features: 

  * default look is flat
  * arrow mark of any size
  * border of any size
  * owner-draw (you can paint OS theme)



Mouse support: 

  * click and holding mouse on arrows
  * click and holding mouse on page-up (area above thumb) / page-down (area below thumb)
  * drag of thumb
