# square brackets

│ **English (en)** │

  


[ ]

The left square bracket `[` is defined in [ASCII](<ASCII.md> "ASCII") as having the value is `91` ([hexadecimal](<Hexadecimal.md> "Hexadecimal") [`$`](<Dollar_sign.md> "Dollar sign")`5B`). In [Pascal](<Pascal.md> "Pascal") it always appears in conjunction with a corresponding right square bracket `]` is defined in ASCII as having the value is `93` (hexadecimal `$5D`) constituting a pair. 

Such a pair is used to: 

  * Static [array](<Array.md> "Array") the [type](<Type.md> "Type") definition
  * Accessing array Elements. An element is accessed by indexing the array name. This is done by placing the index or [variable's](<Variable.md> "Variable") [identifier](<Identifier.md> "Identifier") of the element within square brackets after the name of the array.
  * Define an empty [set](<Set.md> "Set") : `someset := [];`
  * Using brackets to hold set elements
  * [Custom Attributes](<Custom_Attributes.md> "Custom Attributes")
