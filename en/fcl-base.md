Note that about half of them are documented in the "fcl" part of the library/

# Units

  * [ascii85 unit](<ascii85.md> "ascii85") \- ASCII85 encoding/decoding streams
  * [avl_tree unit](</index.php?title=avl_tree&action=edit&redlink=1> "avl tree \(page does not exist\)") \- AVL binary tree implementation used by DOM (in [fcl-xml](<fcl-xml.md> "fcl-xml")). Lazarus codetools also use it in several places.
  * [base64 unit](</index.php?title=base64&action=edit&redlink=1> "base64 \(page does not exist\)") \- base64 encoding/decoding streams
  * [blowfish unit](</index.php?title=blowfish&action=edit&redlink=1> "blowfish \(page does not exist\)") \- Unit implementing blowfish encryption/decryption streams. See also: [[1]](<http://www.freepascal.org/~michael/articles/archives/archives.pdf>) Article demonstrating handling tar, bzip2, gzip, zip files and Blowfish encryption in FreePascal/Lazarus. A good introduction even though it was written some time ago (a lot of functionality has been improved).
  * [bufstream unit](<bufstream.md> "bufstream") \- Buffered stream
  * [cachecls unit](</index.php?title=cachecls&action=edit&redlink=1> "cachecls \(page does not exist\)") \- Generic cache class for FCL
  * [contnrs unit](</index.php?title=contnrs&action=edit&redlink=1> "contnrs \(page does not exist\)") \- Delphi compatible container unit.
  * [custapp unit](</index.php?title=custapp&action=edit&redlink=1> "custapp \(page does not exist\)") \- TCustomApplication class, base class for several "application" object classes.
  * [daemonapp unit](</index.php?title=daemonapp&action=edit&redlink=1> "daemonapp \(page does not exist\)") \- Class for a Daemon application.
  * [eventlog unit](</index.php?title=eventlog&action=edit&redlink=1> "eventlog \(page does not exist\)") \- Unit implementing system log class
  * [fpexprpars unit](</index.php?title=fpexprpars&action=edit&redlink=1> "fpexprpars \(page does not exist\)") \- Expression parser, supports variables, functions and float/integer/string/boolean/datetime operations. See [How To Use TFPExpressionParser](<How_To_Use_TFPExpressionParser.md> "How To Use TFPExpressionParser"); see also [symbolic](</index.php?title=symbolic&action=edit&redlink=1> "symbolic \(page does not exist\)")
  * [fptimer unit](</index.php?title=fptimer&action=edit&redlink=1> "fptimer \(page does not exist\)") \- A generic timer component. Can be used in GUI and non-GUI apps.
  * [gettext unit](</index.php?title=gettext&action=edit&redlink=1> "gettext \(page does not exist\)") \- Unit implementing resource string translation using gettext files
  * [idea unit](</index.php?title=idea&action=edit&redlink=1> "idea \(page does not exist\)") \- The IDEA unit provides IDEA encryption support
  * [inicol unit](</index.php?title=inicol&action=edit&redlink=1> "inicol \(page does not exist\)") \- Collection which can write itself to inifile.
  * [inifiles unit](</index.php?title=inifiles&action=edit&redlink=1> "inifiles \(page does not exist\)") \- Ini files support
  * [iostream unit](</index.php?title=iostream&action=edit&redlink=1> "iostream \(page does not exist\)") \- Implement streams for handling standard input, output and stderr
  * [libtar unit](<libtar.md> "libtar") \- A unit for creating/reading .TAR archives using streams.
  * [maskutils unit](</index.php?title=maskutils&action=edit&redlink=1> "maskutils \(page does not exist\)") \- FormatMaskText implementation
  * [pooledmm unit](</index.php?title=pooledmm&action=edit&redlink=1> "pooledmm \(page does not exist\)") \- Pooled memory manager implementation
  * [rtfpars unit](</index.php?title=rtfpars&action=edit&redlink=1> "rtfpars \(page does not exist\)") \- RTFParser unit.
  * [rttiutils unit](</index.php?title=rttiutils&action=edit&redlink=1> "rttiutils \(page does not exist\)") \- RTTI utility functions, based on RX rtti utils.
  * [streamcoll unit](</index.php?title=streamcoll&action=edit&redlink=1> "streamcoll \(page does not exist\)") \- Collection which can stream itself
  * [streamex unit](</index.php?title=streamex&action=edit&redlink=1> "streamex \(page does not exist\)") \- Stream extensions
  * [streamio unit](</index.php?title=streamio&action=edit&redlink=1> "streamio \(page does not exist\)") \- Streams for standard text files.
  * [syncobjs unit](</index.php?title=syncobjs&action=edit&redlink=1> "syncobjs \(page does not exist\)") \- A unit with synchronization objects
  * [uriparser unit](</index.php?title=uriparser&action=edit&redlink=1> "uriparser \(page does not exist\)") \- Unit to parse complete URI in its parts or to reassemble an URI
  * [wformat unit](</index.php?title=wformat&action=edit&redlink=1> "wformat \(page does not exist\)") \- base class for wtex and whtml. An abstract type to create tables.
  * [whtml unit](</index.php?title=whtml&action=edit&redlink=1> "whtml \(page does not exist\)") \- implementation that renders to html
  * [wtex unit](</index.php?title=wtex&action=edit&redlink=1> "wtex \(page does not exist\)") \- implementation that renders to (La?)TeX
