# Object module

An **object module** is a compiled, [executable program](<Executable_program.md> "Executable program") which is either a set of routines to be called from another program (such as a .so file on [Linux](<Linux.md> "Linux") systems or a .[DLL](<DLL.md> "DLL") file under [Microsoft Windows](</index.php?title=Microsoft_Windows&action=edit&redlink=1> "Microsoft Windows \(page does not exist\)")) or is a compiled program not designed to be run separately which will become part of another program, such as the [source code](<Source_code.md> "Source code") of a [Pascal](<Pascal.md> "Pascal") [unit](<Unit.md> "Unit"), a .OBJ file under Microsoft Windows and MS-DOS, or a .O file in Linux.
