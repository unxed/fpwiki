Portal:WinCE

[![WinCE Logo.png](https://wiki.freepascal.org/images/8/86/WinCE_Logo.png)](</File:WinCE_Logo.png>) This portal provides an overview of development for Windows Embedded Compact (WinCE) with Lazarus and Free Pascal. Windows Embedded Compact, formerly Windows Embedded CE and Windows CE, is an operating system subfamily developed by Microsoft as part of its Windows Embedded family of products.
