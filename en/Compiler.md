The **compiler** (in this case, the [FPC](<FPC.md> "FPC") Pascal Compiler) is the executable program that translates Pascal [source code](<Source_code.md> "Source code") into [assembly language](<Assembly_language.md> "Assembly language") to then be processed by the [assembler](<Assembler.md> "Assembler") into the [application](<Application.md> "Application") that the source code specifies. 

Note that some [Pascal](<Pascal.md> "Pascal") compilers - and most other compilers - directly generate the [executable program](<Executable_program.md> "Executable program") or produce an [object module](<Object_module.md> "Object module") that can be passed to a program linker. In the case of the FPC Pascal Compiler, that job is performed by the assembler program. 

Some Pascal compilers are standalone [executable programs](<Executable_program.md> "Executable program") which are passed a command line and a set of files. Other Pascal compilers provide an [Integrated Development Environment](<IDE.md> "IDE") or _IDE_ , which allows for editing and compilation to be done in a seamless fashion. 

Examples of Pascal compilers include: 

  * [Australian Atomic Energy Commission](</index.php?title=AAEC_Pascal&action=edit&redlink=1> "AAEC Pascal \(page does not exist\)") Pascal Compiler for the IBM 370 Mainframe
  * [Borland Pascal](<Borland_Pascal.md> "Borland Pascal") and [Turbo Pascal](<Turbo_Pascal.md> "Turbo Pascal") which were developed by Borland International for MS-Dos and for Windows 3.1 or as [16-bit](</index.php?title=16-bit&action=edit&redlink=1> "16-bit \(page does not exist\)") applications for Windows 95.
  * [Delphi](<Delphi.md> "Delphi") from Embarcadero (formerly Codegear and Borland International) which produces [32-bit](</index.php?title=32-bit&action=edit&redlink=1> "32-bit \(page does not exist\)") and [64-bit](</index.php?title=64-bit&action=edit&redlink=1> "64-bit \(page does not exist\)") applications for Windows 95/98/NT/Me/2000/XP/Vista/7/8/10.
  * [Kylix](<Kylix.md> "Kylix") from Borland International which produces [32-bit](</index.php?title=32-bit&action=edit&redlink=1> "32-bit \(page does not exist\)") applications for [Linux](<Linux.md> "Linux").
  * [UCSD Pascal](<UCSD_Pascal.md> "UCSD Pascal") for the PDP-11 and Apple II computers, and later for the IBM-PC under MS-Dos running on its own operating system.
