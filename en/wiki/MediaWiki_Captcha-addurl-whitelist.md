    # linking to a lot from the wiki. The whitelist causes the captcha mechanism (little

    # these trusted websites.

    # To prevent any malicious bypassing to let through spam bots, or entering of crazy
    # regex's, this page is 'protected' (only sysops can edit) Want to add a site to the
    # list? Just suggest it on the discussion page. But note that this whitelist ONLY controls
    # the captcha mechanism. That's ALL it does, so it's no big deal really, we don't need
    # to build a huge whitelist of every site we like/trust. For most external linking
    # just solve the captcha puzzle!
