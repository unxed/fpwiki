# How to Create a Custom Lazarus Component

This guide walks you through creating a new visual Lazarus component, from creating the package to registering the component in the IDE. It also includes best practices for naming units and classes to avoid conflicts.

## Step 1: Create the package

  1. In Lazarus, go to **Package → New Package**.
  2. Choose a directory for the package. **The folder name becomes the package name**.


    
    
     Example: Tutorial folder → package name Tutorial.
    

  1. Save the package file (`.lpk`) in the package folder.



## Step 2: Create the unit

Each component lives in its own unit. The unit filename must match the unit name declared inside the file. 

### Create a new unit

  1. In Lazarus, go to **File → New Unit**.
  2. Save the unit inside the package folder.
  3. The **Pascal unit filename should match the component class name** :


  * `TSimpleLED` → `SimpleLED.pas` (unit name = `SimpleLED`)
  * `TOAISimpleLED` → `OAISimpleLED.pas` (unit name = `OAISimpleLED`)



### Add an existing unit

If you already have a `.pas` file: 

  1. In the Package Editor, click **Add → Add Files**.
  2. Select your existing unit file.
  3. Make sure the unit name in the file matches the filename (without extension).



## ⚠ Naming Conflicts and Prefixes

When you create Lazarus components for public release (or even for use across multiple projects), **you must avoid naming conflicts**. 

Lazarus and Free Pascal will **not** allow two units with the same name to exist in the same project. If your file is called `SimpleLED.pas` and another package also has a `SimpleLED.pas`, the compiler won’t know which one to use. 

### ✅ The Solution: Add a Unique Prefix

Use a short, project- or organization-specific prefix in **both** your unit name and your main component class name. 

Element  | Without Prefix  | With Prefix (`oai`)   
---|---|---  
Unit filename  | `SimpleLED.pas` | `oaiSimpleLED.pas`  
`unit` declaration  | `unit SimpleLED;` | `unit oaiSimpleLED;`  
Component class  | `TSimpleLED` | `ToaiSimpleLED`  
  
### 💡 What could _oai_ mean?

`OAI` doesn’t have a universal meaning in Lazarus or Free Pascal — you pick something meaningful to you or your project. 

  * **OAI** could mean **OpenAI** (if you’re releasing it under that brand).
  * It could mean **Owen’s Application Interfaces** (if your name was Owen).
  * It could even be something like **Our Awesome Interface** if you want it fun and memorable.



**Tip:**

  * Prefix should be **short** (2–5 letters)
  * Should be **unique** to you or your organization
  * Apply to **unit names, file names, and class names**
  * Especially important for **published components** that show up in the Lazarus Component Palette



## Step 3: Create icons for the package

### Using the Lazarus Image Editor

  1. Open **Tools → Image Editor**.
  2. Create a 24×24 icon and save it in the package folder.
  3. Assign the icon in the Package Options.



### LRS Explorer

Use the built-in LRS Explorer to embed icons into your unit. 

### Using lazres

Compile resources into a `.lrs` file with the `lazres` tool. 

### Using glazres

Graphical alternative to lazres.
