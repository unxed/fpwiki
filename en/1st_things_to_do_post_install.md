# 1st things to do post install

Once your Lazarus is installed and able to start up, it is good practice to: 

  * Install .chm integrated `F1` help system [manually](<Lazarus_Documentation.md> "Lazarus Documentation") (i.e. copy the [.chm files](<http://www.stack.nl/~marcov/doc-chm.zip>) into the .../chm subdirectory of your local installation, **F1** will then find the files).
  * Familiarise yourself with, and use, the button **Project Options / Test** .
  * Have a brief look at the [IDE tricks](<IDE_tricks.md> "IDE tricks").
