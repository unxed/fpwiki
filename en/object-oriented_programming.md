# object-oriented programming

An object-oriented programming (OOP) is a programming method to write programs using "object" to represent data and [methods](<Method.md> "Method"). The object can, upon request, perform the functions that are known as methods. The object stores data in its internal [variables](<Variable.md> "Variable"). The [`class`](<Class.md> "Class") defines the common features of certain objects. 

The inheritance allows you to make new class definitions based on old definitions (see more about using the [reserved word](<Reserved_word.md> "Reserved word") [`inherited`](<Inherited.md> "Inherited")). A [`constructor`](<Constructor.md> "Constructor") is a method called object creation. A [`destructor`](<Destructor.md> "Destructor") is called when the object is destroyed.
