## AVRPascal

[AVRPascal](<http://akarwowski.pl/index.php?page=electronics&lang=en>) is a Pascal code editor for AVR microcontrollers (ATtiny and ATmega families). It uses the FreePascal compiler to compile source code, and AVRdude to transfer the code to the microcontroller's memory using the USBasp programmer or Arduino boards. 

[![AVRPascal.png](https://wiki.freepascal.org/images/4/45/AVRPascal.png)](</File:AVRPascal.png>)

## Bhyvemgr

[Bhyvemgr](<https://github.com/alonsobsd/bhyvemgr>) is a bhyve management GUI written in Freepascal/Lazarus on [FreeBSD](<https://freebsd.org>). It needs a bunch of tools mostly installed on base system and some installed from ports/packages. Currently it supports amd64 and aarch64. The main goal is to be a desktop user application to easily and quickly setup and run virtual machines on the FreeBSD host. 

[![bhyvemgr.png](https://wiki.freepascal.org/images/a/ab/bhyvemgr.png)](</File:bhyvemgr.png>)

## Convert POs

[Lazarus project](<https://bitbucket.org/matthieugiroux/convertpos>), whose fusion an original po file and the translated po file. You can save your po language file after. 

## Dexed

[dexed](<https://github.com/Akira13641/dexed/>), formerly known as Coedit, is a small, open-source, cross-platform IDE for the [D language](<http://dlang.org/>). It features: 

  * full featured project format and advanced project editor.
  * compile and run directly from the UI.
  * instant run (without saving, script-like).
  * synchronized edition in a block.
  * D2 syntax highlighter, folding, identifier markup.
  * module symbol list.
  * static libraries manager.
  * search and replace.
  * user-defined tools powered by a string interpolation system.
  * [D Completion Daemon](<https://github.com/Hackerpilot/DCD>) integration for completion proposal and source code hints.
  * mini file browser.



[![coedit.linux.kde.png](https://wiki.freepascal.org/images/7/79/coedit.linux.kde.png)](</File:coedit.linux.kde.png>)

## Diacrit

[Diacrit](<https://www.paulherber.co.uk/diacrit/>) is a utility to help with access to Unicode characters, choose the language you want. click the character button and paste into your application. Diacrit was first written in Turbo Pascal for Windows back in 1996, migrated to Delphi, and now upgraded to FPC/Lazarus. 

[![french.png](https://wiki.freepascal.org/images/0/07/french.png)](</File:french.png>) [![armenianlc.png](https://wiki.freepascal.org/images/0/04/armenianlc.png)](</File:armenianlc.png>)

## Double Commander

[Double Commander](<http://sourceforge.net/projects/doublecmd/>) is a cross platform open source file manager with two panels side by side. It is inspired by Total Commander and features some new ideas. 

[![Double Commander2.png](https://wiki.freepascal.org/images/d/de/Double_Commander2.png)](</File:Double_Commander2.png>)

## ExifSpy

[ExifSpy](<https://github.com/wp-xyz/exif_spy>) is a tool for peeking into the binary structure of EXIF metadata of picture files: 

  * Navigate through the jpeg file structure
  * Navigate through the EXIF tag directories
  * Display and analyze binary metadata records (EXIF, IPTC, XMP)
  * Display and analyze jpeg ICC color profiles
  * Embedded hex viewer combining the bytes beginning at the cursor position to conventional data types in both big endian and little endian byte order.



[![exifspy v0.2.0.png](https://wiki.freepascal.org/images/1/18/exifspy_v0.2.0.png)](</File:exifspy_v0.2.0.png>)

## ExPress

[ExPress](<http://code.google.com/p/express-gui>) is a GUI wrapper for UPX (Ultimate Packer for eXecutables). 

## Hex

[Hex](<https://github.com/wp-xyz/Hex>) is an open source hex editor with some features that are useful for analyzing binary files ("reverse-engineering"): 

  * Numeric viewer: displays the byte selected by the cursor and the following bytes of standard Pascal numeric data types (byte, shortint, word, ..., singe, double, real48) as a usual number.
  * Record viewer: allows to construct "records" from the basic Pascal types. The record elements are displayed in "human-readable" form. Commands are available to scroll through the file record by record.
  * Object viewer: displays embedded images.



[![hex-screenshot.png](https://wiki.freepascal.org/images/d/d8/hex-screenshot.png)](</File:hex-screenshot.png>)

## Hexy

[Hexy](<https://github.com/tristan2468/Hexy>) is a cross-platform tool for embedded C developers. It automatically converts binary files into C header files containing hexadecimal arrays for integration into embedded projects. 

## LPTK

[Light Pascal ToolKit](<http://lptk.sourceforge.net>) is a native, Object Pascal language GUI framework. 

## MouseAndKeyInput

[MouseAndKeyInput](<MouseAndKeyInput.md> "MouseAndKeyInput") is a tool for cross-platform manipulation with mouse and key input. You can move mouse cursor to specified location, send clicks and do key presses. It is suitable for GUI testing or program control demonstration. 

## P65Pas

[P65Pas](<https://github.com/t-edson/P65Pas>) is a Pascal compiler and IDE, which generates binary and ASM code for the 6502 CPU. 

[![P65Pas.png](https://wiki.freepascal.org/images/6/6d/P65Pas.png)](</File:P65Pas.png>)

## PasDoc

[PasDoc](<PasDoc.md> "PasDoc") ([webpage](<http://pasdoc.sourceforge.net/>)) is an open-source documentation generator for ObjectPascal source code. It reads documentation from comments in your source code (an option to read it from an external file is also available), and generates nice docs in HTML, LaTeX or other formats. We have a console program, and a cross-platform GUI version using Lazarus. 

## PicPas

[PicPas](<https://github.com/t-edson/PicPas>) is a Open Source Crossplatform Pascal compiler, for midrange PIC microcontrollers (most of the 16F series). No additional libraries or software required to compile. PicPas generates the *.hex file directly. PicPas works with a simplified version of the Pascal language, that has been adapted to work with limited resources small devices. Currently, it only supports basic types. It includes a very complete IDE to facilitate the development. The compiler includes optimization options so the code obtained is fairly compact, as that could generate any commercial compiler. 

[![pp2.png](https://wiki.freepascal.org/images/1/1e/pp2.png)](</File:pp2.png>)

## SVN::Observator

[SVN::Observator](<http://svn-observator.sourceforge.net/>) is a simple tool to monitor svn repositories for new commits. It uses the original svn client to connect to the repositories. Binaries for Linux and Windows are available. 

[![svn-observator 1.png](https://wiki.freepascal.org/images/e/e3/svn-observator_1.png)](</File:svn-observator_1.png>) [![svn-observator 2.png](https://wiki.freepascal.org/images/a/ac/svn-observator_2.png)](</File:svn-observator_2.png>)

## Win32 API Manager

The [API Manager](<http://www.benibela.de/tools_en.html#apim>) is a very old program giving a GUI for Win32 API functions. It can do everything there is an API function for, e.g. list all processes, change their priority or kill them; list all windows and change their attributes (e.g. change a password, edit to a normal, readable edit) ... It was originally written with D4 for Win98, but I ported it to Lazarus and added support for NT-platform functions. So, it should still work nowadays. 

## zDevStudio

[zDevStudio](<https://sourceforge.net/projects/zdevstudio/>) is an open source cross-platform IDE based on [Pasmo](<https://pasmo.speccy.org/>) compiler designed to help coders and retrocoders to develop software for Zilog Z80 8-bit CPU. 

[![zDevStudio.jpg](https://wiki.freepascal.org/images/e/e1/zDevStudio.jpg)](</File:zDevStudio.jpg>)
