# Object Pascal

**Object Pascal** is a collective term for [Pascal](<Pascal.md> "Pascal") dialects that have features which allow [object-oriented programming (OOP)](<Object_Oriented_Programming_with_Free_Pascal_and_Lazarus.md> "Object Oriented Programming with Free Pascal and Lazarus"). The first Pascal versions supporting [OOP](<Glossary.md> "Glossary") were [Clascal](<Clascal.md> "Clascal") and [Macintosh Pascal](<Mac_Pascal.md> "Mac Pascal"). More modern implementations extend the class model as in [Delphi](<Delphi.md> "Delphi") and [Free Pascal](<Free_Pascal.md> "Free Pascal"). 

The first implementation of Object Pascal was developed by [Larry Tesler](</index.php?title=Larry_Tesler&action=edit&redlink=1> "Larry Tesler \(page does not exist\)") at Apple Computer in collaboration with [Niklaus Wirth](<Niklaus_Wirth.md> "Niklaus Wirth").
