Кроме Lazarus и FPC, эта wiki содержит странички других связанных проектов: 

  * [MSEide & MSEgui](<MSEide_&_MSEgui.md> "MSEide & MSEgui") \- альтернативная IDE и набор визуальных компонентов для разработки программ на FreePascal. Работает в Linux и Windows. 
  * [Key Objects Library и Mirror Classes Kit](<../ru/KOL-CE.md> "KOL-CE/ru"): 
    * Key Objects Library (KOL) - набор объектов для разработки компактных Win32/Windows CE/Pocket PC/Windows Mobile GUI-приложений, в том числе и с использованием Free Pascal. 
    * Mirror Classes Kit (MCK) - пакет для Lazarus, позволяющий визуально разрабатывать KOL-приложения. 
  * [Powtils](<Powtils.md> "Powtils") \- набор пакетов для веб-разработки с помощью FreePascal и Delphi. 
  * [Light Web Server](<Light_Web_Server.md> "Light Web Server")
  * [Web Application Template Engine](<Web_Application_Template_Engine.md> "Web Application Template Engine")
  * [fpGUI](<fpGUI.md> "fpGUI") \- ещё один набор визуальных компонентов, написанных с помощью Object Pascal. Он позволяет обеспечивать совместимость исходного кода между Linux, MS Windows, *BSD и встраиваемыми устройствами, такими как Embedded Linux и Windows CE. Компоненты непосредственно связаны с основной оконной системой (Xlib, GDI) и это позволяет избежать использования больших библиотек (таких как Qt, GTK и так далее), что позволяет создавать легко развёртываемые приложения. Также включает визуальную IDE, построенную на основе этих компонентов.
