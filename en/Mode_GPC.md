# Mode GPC

│ **English (en)** │  **[español (es)](</Mode_GPC/es> "Mode GPC/es")** │  **[français (fr)](</Mode_GPC/fr> "Mode GPC/fr")** │  **[русский (ru)](<../ru/Mode_GPC.md> "Mode GPC/ru")** │    
****

The [compiler mode](<Compiler_Mode.md> "Compiler Mode") `{$mode GPC}` was supported by [FPC](<FPC.md> "FPC") until version 2.2 (commented out in [revision 6518](<https://gitlab.com/freepascal.org/fpc/source/commit/5aef9bc086e9098a30fe67b2ac0658637eff8ce5>)). The mode’s intention was to compile only code that is accepted by the [GNU Pascal](<GNU_Pascal.md> "GNU Pascal") compiler. 

As an alternative, the closest mode to the former `{$mode GPC}` will be [`{$mode extendedPascal}`](<Mode_extendedpascal.md> "Mode extendedpascal"). As of 2022, however, it is not operational yet.
