# GradControls

## About

GradControls is a Package of "Gradient Controls". There are currently 2 Components in this Package: 

  * [TGradButton](<TGradButton.md> "TGradButton") \- Version: 1.5 - stable
  * [TGradPageControl](<TGradPageControl.md> "TGradPageControl") \- Version 0.1 - very unstable - currently in development
