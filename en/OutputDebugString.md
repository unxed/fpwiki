# OutputDebugString

**OutputDebugString( )** is a Windows method for emitting a text string to some output device (window/file/external debugger). 

Lazarus will show these messages in the [IDE Window: Event Log](<IDE_Window__Event_Log.md> "IDE Window: Event Log") accessible from [Main menu](<Main_menu.md> "Main menu") > [View](<Main_menu.md> "Main menu") > Debug Windows > Event Log. Alternatively, the shortcut keys `Ctrl`+`Alt`+`V` will open the Event Log window. 

Note: You will need to include the Windows unit for the WinAPI in your application's Uses clause.
