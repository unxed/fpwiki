# Lazarus release version for Ubuntu

│ **English (en)** │  **[polski (pl)](</Lazarus_release_version_for_Ubuntu/pl> "Lazarus release version for Ubuntu/pl")** │    
****

One might try: 
    
    
       sudo apt install lazarus
    

may be helpful to also run: 
    
    
       sudo apt install fpc fpc-source lcl
    

which works for Ubuntu 18.04 at least. 

Additional, parallel installs with [fpcupdeluxe](<fpcupdeluxe.md> "fpcupdeluxe") might not work after this, unless old installs are purged. Note: This page contained (see history) different outdated info which does not work anymore.
