# Operating System

│ **English (en)** │

An Operating System is the primary program which is used to control a computer. [MS-DOS](<DOS.md> "DOS"), [Windows](<Portal_Windows.md> "Portal:Windows"), [ReactOS](<ReactOS.md> "ReactOS"), [Linux](<Portal_Linux.md> "Portal:Linux"), [FreeBSD](<FreeBSD.md> "FreeBSD") and [UCSD Pascal](<UCSD_Pascal.md> "UCSD Pascal") are all operating systems which run on standard PCs. 

Other operating systems that are supported by Lazarus / Free Pascal include [Android](<Portal_Android.md> "Portal:Android"), [iOS](<Portal_iOS.md> "Portal:iOS") and [macOS](<Portal_Mac.md> "Portal:Mac").
