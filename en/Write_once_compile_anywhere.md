# Write once compile anywhere

│ **English (en)** │  **[suomi (fi)](</Write_once_compile_anywhere/fi> "Write once compile anywhere/fi")** │  **[polski (pl)](</Write_once_compile_anywhere/pl> "Write once compile anywhere/pl")** │    
****

Write once, compile anywhere (WOCA) means that the [application](<Application.md> "Application") can be written first and then compiled to another environment without having to change the [source code](<Source_code.md> "Source code") of the [program](<Program.md> "Program"). A good example of such an application is [Lazarus](<Lazarus.md> "Lazarus").
