# Contributed Units

An extensive list of community-contributed units for Free Pascal is available at the [Free Pascal site](<http://www.freepascal.org/contrib/contribs.html>). Contributed Units for Lazarus are listed at [Components and Code examples](<Components_and_Code_examples.md> "Components and Code examples"). Another extensive archive of units for Lazarus is provided with the [Lazarus Code and Component Repository](<http://sourceforge.net/projects/lazarus-ccr/>). 

## Additional contributed units

  * [WOL](<http://dexrow.blogspot.com/2007/08/wol.html>): Window Object Library, an object library of windows written in object pascal and [wolgui](<http://dexrow.blogspot.com/2007/08/wol.html>) library and RAD for free pascal



## External links

  * [Free Pascal Contributed Units](<http://www.freepascal.org/contrib/contribs.html>)
  * [Lazarus Code and Component Repository](<http://sourceforge.net/projects/lazarus-ccr/>)
  * [OpenGPSX](<http://sourceforge.net/projects/opengpsx/>), Lazarus Component for GPS interface programming
  * [PascalSCADA](<http://www.pascalscada.com>), a set of Lazarus components supporting the development of industrial applications
  * [CurlPas and TidyPas](<http://sourceforge.net/projects/curlpas/>), bindings and object-oriented wrapper for LibCURL and HTML-tidy.
