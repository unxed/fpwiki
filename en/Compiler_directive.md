# Compiler directive

│ **English (en)** │

A [compiler directives](<http://freepascal.org/docs-html/current/prog/progch1.html#x5-40001>) give instructions to the [compiler](<Compiler.md> "Compiler") to preprocess the information before actual compilation starts. All these directives begin with a [$ (dollar sign )](<Dollar_sign.md> "Dollar sign") immediately following the opening [{ (Left curly bracket)](<Left_curly_bracket.md> "Left curly bracket"). The compiler directive is always specified as a [comment](<Comments.md> "Comments") using curly braces: 
    
    
     {$DIRECTIVE [value]} 
    

There are two types of directives in use: 

  * [local compiler directives](<local_compiler_directives.md> "local compiler directives")
  * [global compiler directives](<global_compiler_directives.md> "global compiler directives")
