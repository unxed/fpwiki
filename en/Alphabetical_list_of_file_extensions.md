# Alphabetical list of file extensions

**Please merge into the much completer list here:[File extensions](<File_extensions.md> "File extensions")**

  * bmp - bitmap : [ TImage ](<Additional_tab.md> "Additional tab")
  * chm - Compiled Help File : [chm](<chm.md> "chm")
  * csv - Comma-Separated Values : [CSV](<CSV.md> "CSV")
  * cur - Cursor : [ TImage ](<Additional_tab.md> "Additional tab")
  * dbf - DBase (FoxPro etc) file: [Lazarus_Tdbf_Tutorial](<Lazarus_Tdbf_Tutorial.md> "Lazarus Tdbf Tutorial")
  * docx - Microsoft Office Open XML Document: [ docxvectorialwriter](<fpvectorial.md> "fpvectorial")
  * dxf - Drawing eXchange Format : [ dxfvectorialreader ](<fpvectorial.md> "fpvectorial")
  * icns - Mac OS X icon : [ TImage ](<Additional_tab.md> "Additional tab")
  * ini - Initialization file : [Using INI Files](<Using_INI_Files.md> "Using INI Files")
  * jfif - Joint Picture Expert Group : [ TImage ](<Additional_tab.md> "Additional tab")
  * jpe - Joint Picture Expert Group : [ TImage ](<Additional_tab.md> "Additional tab")
  * jpeg - Joint Picture Expert Group : [ TImage ](<Additional_tab.md> "Additional tab")
  * jpg - Joint Picture Expert Group : [ TImage ](<Additional_tab.md> "Additional tab")
  * json - JavaScript Object Notation : [JSON](<JSON.md> "JSON")
  * las - ASPRS LASer file format : [ lasvectorialreader ](<fpvectorial.md> "fpvectorial")
  * ods - OpenOffice.org Calc spreadsheet File Format : [FPSpreadsheet](<FPSpreadsheet.md> "FPSpreadsheet")
  * odt - OpenDocument Text (OpenOffice.org Writer word processor File Format): [ odtvectorialwriter](<fpvectorial.md> "fpvectorial")
  * pbm - Portable bitmap : [ TImage ](<Additional_tab.md> "Additional tab")
  * [pdf](<PDF.md> "PDF") \- Portable Document Format : [fcl-pdf](<fcl-pdf.md> "fcl-pdf")
  * pgm - Portable graymap : [ TImage ](<Additional_tab.md> "Additional tab")
  * png - Portable network graphic : [ TImage ](<Additional_tab.md> "Additional tab")
  * ppm - Portable pixmap : [ TImage ](<Additional_tab.md> "Additional tab")
  * svg - Scalable Vectorial Graphics : [ svgvectorialreader,svgvectorialwriter ](<fpvectorial.md> "fpvectorial")
  * svgz - Compressed Scalable Vector Graphics File: [ svgzvectorialreader ](<fpvectorial.md> "fpvectorial")
  * tif - Tagged Image File Format : [ TImage ](<Additional_tab.md> "Additional tab")
  * tiff - Tagged Image File Format : [ TImage ](<Additional_tab.md> "Additional tab")
  * wmf - The Windows Metafile [ wmfvectorialreader, wmfvectorialwriter](<fpvectorial.md> "fpvectorial")
  * xls - Microsoft Excel File Format : [FPSpreadsheet](<FPSpreadsheet.md> "FPSpreadsheet")
  * xlsx - Microsoft Office Open XML Excel File Format : [FPSpreadsheet](<FPSpreadsheet.md> "FPSpreadsheet")
  * xml - Extensible Markup Language : [XML](<XML.md> "XML")
  * zip - A .ZIP file may contain one or more files or directories that may have been compressed: [paszlib](<paszlib.md> "paszlib")
