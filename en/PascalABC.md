# PascalABC.net

**PascalABC.net** is a free LGPL-licensed compiler and IDE for [Object Pascal](<Object_Pascal.md> "Object Pascal"). It targets the .NET platform and supports MS Windows, and, with the help of additional libraries, Linux and macOS.
