# Reserved word

│ **English (en)** │  **[Esperanto (eo)](</Reserved_word/eo> "Reserved word/eo")** │  **[suomi (fi)](</Reserved_word/fi> "Reserved word/fi")** │  **[русский (ru)](<../ru/Reserved_word.md> "Reserved word/ru")** │    
****

A reserved word is a word which has a special grammatical meaning to a language and cannot be used as an [identifier](<Identifier.md> "Identifier"). This is the biggest difference between the [keywords](<Keyword.md> "Keyword"). Not all keywords are reserved words. But all the reserved words are keywords. 

See [Pascal](<Pascal.md> "Pascal") [reserved words](<Reserved_words.md> "Reserved words").
