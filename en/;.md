## Welcome to the Free Pascal and Lazarus Wiki

The goal of this Wiki is to collect and store the knowledge necessary for the productive use of Free Pascal, Lazarus and [related projects](<Related_projects.md> "Related projects"). The Wiki is intended to be the first port of call for users looking for information on how to use the tools provided by those projects. 

The Free Pascal Compiler already has [user documentation](<https://www.freepascal.org/docs.html>) available in several formats. [FPC developer information](<FPC_development.md> "FPC development"), and subjects not yet [properly documented](<FPC_documentation.md> "FPC documentation"), is stored in this Wiki. Lazarus has some gaps in its [user documentation](<https://sourceforge.net/projects/lazarus/files/Lazarus%20Documentation/>) and so this Wiki is a place where anyone can edit, improve and expand the [Lazarus documentation](<Lazarus_Documentation.md> "Lazarus Documentation"). 

New to Wikis? No problem. See the [WikiPedia Tutorial](<http://en.wikipedia.org/wiki/Wikipedia:Tutorial>). A [Sand Box](<Sand_Box.md> "Sand Box") is available for new Wiki users to practise in before editing real content. 

If you have any Wiki-related problems, leave a note or suggestion on the [Site Feedback](<Site_Feedback.md> "Site Feedback") page or make a post in [this Forum](<https://forum.lazarus.freepascal.org/index.php?board=8.0>).

## Bug Tracker

The [Lazarus Bug Tracker](<https://gitlab.com/freepascal.org/lazarus/lazarus/-/issues>) and the [Free Pascal Bug Tracker](<https://gitlab.com/freepascal.org/fpc/source/-/issues>) are the places to go to check if the anomaly you have encountered has already been recorded as a Free Pascal Compiler or Lazarus IDE bug and, if not, you can lodge a bug report (see [How do I create a bug report](<How_do_I_create_a_bug_report.md> "How do I create a bug report")) so that it can be fixed. Even better, lodge a patch if you can (see [Creating A Patch](<Creating_A_Patch.md> "Creating A Patch")) with the bug report.
