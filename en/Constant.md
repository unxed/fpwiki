# Constant

│ **English (en)** │

A **constant** is a [variable](<Variable.md> "Variable") that does not change, it has a final value. 

Constants are defined in the [`const` section](<Const.md> "Const") of a [Free Pascal](<FPC.md> "FPC") [program](<Program.md> "Program"). When a symbol is defined as constant, the [Free Pascal compiler](<Compiler.md> "Compiler") can often do some optimizations to make the output code faster or smaller. 

  
Some special Free Pascal constants are: 

Logical truth values 

  * [`false`](<False.md> "False")
  * [`true`](<True.md> "True")



data type limits 

  * [`nil`](<Nil.md> "Nil"): empty [pointer](<Pointer.md> "Pointer") value
  * [`maxint`](<maxint.md> "maxint"): largest possible [`integer`](<Integer.md> "Integer") value



  
The mathematical value [π](<Pi.md> "Pi") is realized as a function in [`system.pi`](<https://www.freepascal.org/docs-html/rtl/system/pi.html>).
