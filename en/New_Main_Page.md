# New Main Page

│ **English (en)** │

Welcome to the Lazarus and Free Pascal Wiki

The goal of this wiki is to be knowledgebase for FPC/Lazarus and related projects. FPC has already a good user documentation in several formats, [FPC developer information](<FPC_development.md> "FPC development") and subjects not yet [properly documented](<FPC_documentation.md> "FPC documentation") is collected in this wiki. Lazarus on the other hand has some gaps in the user documentation so this area is an "open document", or "wiki" where anyone can edit and add content. The wiki speeds things up by making it possible to make changes and additions with a browser! For tutorials, please take a look at the [30 Second Quick Wiki Tutorial](<http://www.chat11.com/30_Second_Quick_Wiki_Tutorial>) or the [WikiPedia Tutorial](<http://en.wikipedia.org/wiki/Wikipedia:Tutorial>). A [Sand Box](<Sand_Box.md> "Sand Box") is available for practice. If you have any problems, please notify the site [administrator](<http://sourceforge.net/users/vlx/>) or post a bug report on the [Lazarus-CCR](<http://sourceforge.net/projects/lazarus-ccr>) SF site. You can also leave a note or suggestion on our [Site Feedback](<Site_Feedback.md> "Site Feedback") page. For **project history** , see the [History](<History.md> "History") page.

## Downloads

All currently available components and packages are available on the [Lazarus-CCR Sourceforge files area](<http://sourceforge.net/project/showfiles.php?group_id=92177>). The Free Pascal Compiler and current test versions of Lazarus can be found at [The Lazarus Sourceforge site](<http://sourceforge.net/project/showfiles.php?group_id=89339>). Additional documentation on these packages can also be found on the [Components and Code examples](<Components_and_Code_examples.md> "Components and Code examples") wiki page if the person who contributed the code created one there. The Compiler and a lot of contributed code can be found on the [Free Pascal Compiler download mirrors](<http://www.freepascal.org/sdown.html>) and on the [Lazarus IDE website](<http://lazarus.freepascal.org>). Lazarus Snapshots download locations can be found [ here](<Lazarus_Snapshots_Downloads.md> "Lazarus Snapshots Downloads"). 

## Mailing lists

New and experienced users alike are invited to join the Lazarus-ccr [announce](<http://lists.sourceforge.net/lists/listinfo/lazarus-ccr-announce>) and [general](<http://lists.sourceforge.net/lists/listinfo/lazarus-ccr-general>) mailing lists. 

Perhaps even more useful are the [Lazarus](<http://www.lazarus.freepascal.org/modules.php?op=modload&name=StaticPage&file=index&sURL=maill>) IDE mailing list 

and the [FreePascal](<http://www.freepascal.org/maillist.html>) developers or announcement mailing lists. 

## Who is working on what?

If you're currently converting a component or library or you need something converted, please post it on the [Current conversion projects](<Current_conversion_projects.md> "Current conversion projects") page. These postings will help guide developers who want to convert components that are in demand... and also prevent the duplicated effort of two people converting the same package. 

## References, Links and Resources

### Lazarus IDE

News and information about the status of the Lazarus IDE can be found on the [Lazarus IDE website](<http://lazarus.freepascal.org>). Releases of the Lazarus IDE and FreePascal compiler can be downloaded from there. The [Lazarus file area](<http://sourceforge.net/project/showfiles.php?group_id=89339>) also has the latest packages of the compiler and IDE available for download. 

#### Active Lazarus Projects

Our current listing of [Projects using Lazarus](<Projects_using_Lazarus.md> "Projects using Lazarus") with publicly accessible websites and Lazarus related files to download. 

In the [Lazarus Application Gallery](<Lazarus_Application_Gallery.md> "Lazarus Application Gallery") you can see some screenshots of applications created with Lazarus. 

#### Super Sites and Link Farms

Our current collection of Delphi/Kylix related sites can be found on our [Page Of Code Sites](<Page_Of_Code_Sites.md> "Page Of Code Sites"). Please add to it if you know of a good site that hasn't been listed yet. 

#### Specialized Search Engines

There are some outstanding search and knowledge bases online that can be a great help for learning new techniques and solving problems. Tamarack Associates operates a fast [search](<http://www.tamaracka.com/search.htm>) engine specifically for the Borland usenet archives. Mer Systems Inc. provides a similar search [engine](<http://www.mers.com/searchsite.html>). Another outstanding source of information along with a sitewide [search](<http://www.efg2.com/Lab/search.htm>) capability is Earl F. Glynn's Computer Lab and Reference [Library](<http://www.efg2.com/>). 

#### Case Studies

An [opportunity for Lazarus users](<Case_Studies.md> "Case Studies") to explain why Lazarus is the IDE of choice. 

#### Presenting FPC/Lazarus on a trade show

FPC/Lazarus were present with a booth at the [Systems 2005](<Systems_2005.md> "Systems 2005") and the [Systems 2006](<Systems_2006.md> "Systems 2006") in Munich. Based on the experiences made on these trade shows, we've collected some [information](<Preparing_a_booth_on_a_trade_show.md> "Preparing a booth on a trade show") to help future preparations of a trade show booth.
