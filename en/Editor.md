# Editor

An **editor** is an [application](<Application.md> "Application") program that allows a user to type in [text](<Text.md> "Text") to be allowed to save it as a [file](</File> "File") on the computer system they are using. Where the editor is a standalone program, the user can exit the editor, then provide the file they were editing to the [compiler](<Compiler.md> "Compiler") to be translated as [source code](<Source_code.md> "Source code") into an [object module](<Object_module.md> "Object module") or an [executable program](<Executable_program.md> "Executable program"). 

Where the editor is part of an [Integrated Development Environment](<IDE.md> "IDE") or _IDE_ , the user could compile the program from the editor and have the compiler inform them exactly where the error is in the code, then position their editing focus to the specific line where the error was found.
