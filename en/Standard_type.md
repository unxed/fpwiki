# Standard type

****

There are certain [data types](<Data_type.md> "Data type") which are defined by a [Pascal](<Pascal.md> "Pascal") [compiler](<Compiler.md> "Compiler") as **standard data types**. These types are generally the _atomic_ data structures used by a [Pascal](<Pascal.md> "Pascal") [program](<Program.md> "Program"), as variables and constants that would be made up of them can't be created from something else without these types. The typical standard types include: 

  * [boolean](<Boolean.md> "Boolean") \- [true](<True.md> "True") or [false](<False.md> "False")
  * [char](<Char.md> "Char") \- Character
  * [real](<Real.md> "Real") \- Numbers with decimal points or exponents
  * [integer](<Integer.md> "Integer") \- Whole numbers
  * [set](<Set.md> "Set") \- A group of values



Additional standard types which are defined by more advanced compilers include: 

  * [object](<Object.md> "Object") \- used to declare object types
  * [string](<String.md> "String") \- used to declare strings which are handled automatically by the compiler and [run-time library](<RTL.md> "RTL").
