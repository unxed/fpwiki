## Goal

Replace the current epikwiki web site to mediawiki format. I hope the more open nature of mediawiki will help the growth of the lazarus documentation. 

## Phases

  1. Move all existing pages to media wiki format
  2. Check if all pages are converted correctly and all original contributors properly attributed.
  3. Add new pages and possible restructure current pages.



Future enhancements (wild ideas allowed)

  1. Systematic translations of pages (after all the wikipedia is multilingual too).
  2. Import / export of fpdoc pages, so that the wiki can be used as doceditor.
  3. Off Line Documentation?
