# Underscore

_ 

In [ASCII](<ASCII.md> "ASCII"), the character code decimal `95` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `5F`) is defined to be `_` (Low line sign). 

## Lazarus

In Lazarus the `_` is used 

  * in [`TMaskEdit`](<TMaskEdit.md> "TMaskEdit") indicate EditMask is formed with a pattern of character with the following meaning: automatically put a space.
