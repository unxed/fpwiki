# !

! 

In [ASCII](<ASCII.md> "ASCII"), the character code decimal `33` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `21`) is defined to be `!` (Exclamation mark). 

## Lazarus

In Lazarus the `!` is used to 

  * in [`TMaskEdit`](<TMaskEdit.md> "TMaskEdit") indicate EditMask is formed with a pattern of character with the following meaning: Trim leading blanks, otherwise trim trailing blanks from the data.
