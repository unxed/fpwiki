# Package List

│ **English (en)** │    
****  
****

This particular page is about the **packages** directory in FPC source where all non-RTL packages are kept. 

For other meanings of **Package** in the combined FPC/Lazarus projects see [Packages(disambiguation)](<packages\(disambiguation\).md> "packages\(disambiguation\)"). 

  * [a52](</index.php?title=a52&action=edit&redlink=1> "a52 \(page does not exist\)") \- Unit for A-52 stream decoder. See [SourceForge Page liba52](<http://liba52.sourceforge.net/>)
  * [amunits](<amunits.md> "amunits") \- Amiga related units (68k?)
  * [aspell](</index.php?title=aspell&action=edit&redlink=1> "aspell \(page does not exist\)") \- Aspell header unit.
  * [bfd](<bfd.md> "bfd") \- Header to GNU Binary File Descriptor library (part of binutils)
  * [bzip2](</index.php?title=bzip2&action=edit&redlink=1> "bzip2 \(page does not exist\)") \- bzip2 decoding. Turbo Pascal object, standalone, not a header.
  * [cairo](</index.php?title=cairo&action=edit&redlink=1> "cairo \(page does not exist\)") \- Headers for cairo, a vector graphics library with display and print output. (GTK related, win32 prepared)
  * [cdrom](<cdrom.md> "cdrom") \- A linux/windows unit to detect cdrom drives, and get a list of TOC entries (Linux version=Ancient?)
  * [chm](<chm.md> "chm") \- .CHM helpfile reader/writer package. Used for textmode IDE, fpdoc, lazarus chmhelp component/package.
  * [cocoaint](<cocoaint.md> "cocoaint") \- Interfaces to Mac OS X Objective-C frameworks using the [Objective-Pascal](<FPC_PasCocoa.md> "FPC PasCocoa") syntax
  * [dbus](</index.php?title=dbus&action=edit&redlink=1> "dbus \(page does not exist\)") \- Headers for dbus inter-process communication library. See also the [FPC and DBus](<FPC_and_DBus.md> "FPC and DBus") article
  * [dts](</index.php?title=dts&action=edit&redlink=1> "dts \(page does not exist\)") \- libdts headers, which provides a low-level interface to decoding audio frames encoded using DTS Coherent Acoustics
  * [fcl-async](<fcl-async.md> "fcl-async") \- Provides Unix-only units for asynchronous input/output.
  * [fcl-base](<fcl-base.md> "fcl-base") \- Contains a number of units that are either really "base" functionality or more misc stand-alone units.
  * [fcl-db](<fcl-db.md> "fcl-db") \- [FCL](<FCL.md> "FCL") Database support (including sqldb and tdbf)
  * [fcl-extra](<fcl-extra.md> "fcl-extra") \- [FCL](<FCL.md> "FCL") former fcl-base parts with many dependancies. Currently Daemon/service unit "daemonapp".
  * [fcl-fpcunit](<fcl-fpcunit.md> "fcl-fpcunit") \- [FCL](<FCL.md> "FCL") FPCUNIT testing framework
  * [fcl-image](<fcl-image.md> "fcl-image") \- [FCL](<FCL.md> "FCL") fpimage, fpcanvas generic image support plus helpers.
  * [fcl-json](<fcl-json.md> "fcl-json") \- A JSON (Javascript Object Notation) implementation
  * [fcl-net](<fcl-net.md> "fcl-net") \- Networking parts of the FCL, including the former [netdb](<Netdb.md> "Netdb") \- DNS resolving
  * [fcl-passrc](<fcl-passrc.md> "fcl-passrc") \- Units for dealing with Pascal source files
  * [fcl-process](<fcl-process.md> "fcl-process") \- Provides an easy way to start and manipulate the running of other programs (processes) by your application.
  * [fcl-registry](<fcl-registry.md> "fcl-registry") \- Provides access to the registry
  * [fcl-res](<fcl-res.md> "fcl-res") \- Provides resource handling for various executable formats
  * [fcl-web](<fcl-web.md> "fcl-web") \- A server side web system for FPC
  * [fcl-xml](<fcl-xml.md> "fcl-xml") \- XML, XHTML and HTML sax based parsing, related DOM units and writers.
  * [fftw](</index.php?title=fftw&action=edit&redlink=1> "fftw \(page does not exist\)") \- FFTW - Fastest Fourier Transform in the West library (so apparantly the Eastern one is faster?)
  * [fpgtk](</index.php?title=fpgtk&action=edit&redlink=1> "fpgtk \(page does not exist\)") \- Old fpgtk framework, used to be used for fpde (documentation editor).
  * [fpindexer](<fpindexer.md> "fpindexer") \- Text, Pascal, HTML, database indexer with database/flat file backend.
  * [fpvectorial](<fpvectorial.md> "fpvectorial") \- A library for reading, writing and modifying vectorial images.
  * [fpmkunit](</index.php?title=fpmkunit&action=edit&redlink=1> "fpmkunit \(page does not exist\)") \- Linkable parts of fpmake and fppkg subsystem
  * [fv](<Free_Vision.md> "Free Vision") \- Free Vision is an application framework that allows you to design user friendly text mode applications.
  * [fuse](</index.php?title=fuse&action=edit&redlink=1> "fuse \(page does not exist\)") \- Bindings for libfuse, a library of a daemon that allows implementations of filesystem(-mapping)s in userspace
  * [gbaunits](</index.php?title=gbaunits&action=edit&redlink=1> "gbaunits \(page does not exist\)") \- Gameboy Advance libraries
  * [gdbint](<gdbint.md> "gdbint") \- Interface to gdblib. (static linking to GDB), for the IDE.
  * [gdbm](<gdbm.md> "gdbm") \- Interface to the GNU database system. (libgdbm)
  * [ggi](<ggi.md> "ggi") \- Interface to libGGI (General Graphic Interface)
  * [gmp](<gmp.md> "gmp") \- interface to libGMP (GNU Multiple Precision Arithmetic Library, library for handling "big" numbers)
  * [gnome1](</index.php?title=gnome1&action=edit&redlink=1> "gnome1 \(page does not exist\)") \- Headers for older Gnome-1 version, Gnome is a desktop library.
  * [graph](</index.php?title=graph&action=edit&redlink=1> "graph \(page does not exist\)") \- Implementation of Graph unit compatible to that one originally available with TP/BP
  * [gtk1](<gtk1.md> "gtk1") \- gtk1 headers
  * [gtk2](<gtk2.md> "gtk2") \- gkt2 headers
  * [hash](<hash.md> "hash") \- Contains implementations for crc, md5, NTLM (1?) and, under Linux, crypt. Crypt might be better used from pkg "user"
  * [hermes](<hermes.md> "hermes") \- Port of the "hermes" library. Graphics related
  * [httpd13](<FPC_and_Apache_Modules.md> "FPC and Apache Modules") \- A translation of the Apache 1.3.x headers to develop modules.
  * [httpd20](<FPC_and_Apache_Modules.md> "FPC and Apache Modules") \- A translation of the Apache 2.0.x headers to develop modules.
  * [httpd22](<FPC_and_Apache_Modules.md> "FPC and Apache Modules") \- A translation of the Apache 2.2.x headers to develop modules.
  * [ibase](<ibase.md> "ibase") \- Interbase and Firebird headers
  * [imagemagick](<PascalMagick.md> "PascalMagick") \- ImageMagick headers for pascal.
  * [imlib](</index.php?title=imlib&action=edit&redlink=1> "imlib \(page does not exist\)") \- A dynamic image creation library. See [Imlib documentation](<http://www.fifi.org/doc/imlib-base/html/>). (N.B. this is different from Imlib2)
  * [iconvenc](<iconvenc.md> "iconvenc") \- A header translation of the iconv library headers.
  * [ldap](</index.php?title=ldap&action=edit&redlink=1> "ldap \(page does not exist\)") \- Headers for OpenLDAP - An implementation of the Lightweight Directory Access Protocol. See [OpenLDAP Homepage](<http://www.openldap.org/>)
  * [libc](</index.php?title=libc&action=edit&redlink=1> "libc \(page does not exist\)") \- Deprecated Kylix compatibility lib. Linux/x86 only. See [libc unit](<libc_unit.md> "libc unit")
  * [libcurl](</index.php?title=libcurl&action=edit&redlink=1> "libcurl \(page does not exist\)") \- A header translation of the libcurl library headers
  * [libgd](<libgd.md> "libgd") \- GD is an open source code library for the dynamic creation of images. See [LibGD Homepage](<http://www.libgd.org/>)
  * [libndsfpc](</index.php?title=libndsfpc&action=edit&redlink=1> "libndsfpc \(page does not exist\)") \- Nintendo DS libraries
  * [libpng](<libpng.md> "libpng") \- Interface to the libpng library. This library can be used to read/write/manipulate image files in PNG format
  * [librsvg](</index.php?title=librsvg&action=edit&redlink=1> "librsvg \(page does not exist\)") \- Free, Open Source SVG Rendering library. See [page in Gnome.org](<https://wiki.gnome.org/Projects/LibRsvg>)
  * [libxml2](</index.php?title=libxml2&action=edit&redlink=1> "libxml2 \(page does not exist\)") \- Headers for Libxml2, the XML C parser and toolkit developed for the Gnome project. See [libxml2 Homepage](<http://xmlsoft.org/>)
  * [lua](</index.php?title=lua&action=edit&redlink=1> "lua \(page does not exist\)") \- Headers for lua scripting language
  * [mad](</index.php?title=mad&action=edit&redlink=1> "mad \(page does not exist\)") \- libmad header, (MPEG Audio Decoder) Also part of openal now?
  * [matroska](</index.php?title=matroska&action=edit&redlink=1> "matroska \(page does not exist\)") \- An extensible open standard Audio/Video container. See [Matroska Homepage](<http://www.matroska.org/>)
  * [modplug](</index.php?title=modplug&action=edit&redlink=1> "modplug \(page does not exist\)") \- headers for modplug decoder. see [sourceforge page ModPlug XMMS Plugin](<http://modplug-xmms.sourceforge.net/>)
  * [mysql](<mysql.md> "mysql") \- Headers for mysql database client library for several different versions
  * [ncurses](<ncurses.md> "ncurses") \- General unix terminal support library.
  * [newt](</index.php?title=newt&action=edit&redlink=1> "newt \(page does not exist\)") \- Erik Troan's newt text-mode windowing toolkit
  * [numlib](<numlib.md> "numlib") \- Numeric math lib (TP dialect) from TU/E.
  * [odbc](<odbc.md> "odbc") \- Headers for ODBC library.
  * [objcrtl](</index.php?title=objcrtl&action=edit&redlink=1> "objcrtl \(page does not exist\)") A package that is enabled for Darwin/i386/x86_64/arm but not for PPC/PPC64. "Objective-C Runtime-Library"
  * [oggvorbis](</index.php?title=oggvorbis&action=edit&redlink=1> "oggvorbis \(page does not exist\)") \- An open music codec and container format. See [OggVorbis Homepage](<http://www.vorbis.com/>)
  * [openal](</index.php?title=openal&action=edit&redlink=1> "openal \(page does not exist\)") \- A cross-platform 3D audio API See [OpenAL Homepage](<http://connect.creativelabs.com/openal/default.aspx>)
  * [OpenCL](<OpenCL.md> "OpenCL") \- Headers for Open Computing Language
  * [opengl](<OpenGL.md> "OpenGL") \- An interface to OpenGL (Open Graphics Library)
  * [openssl](</index.php?title=openssl&action=edit&redlink=1> "openssl \(page does not exist\)") \- Headers for openssl, a secure sockets library.
  * [oracle](<Oracle.md> "Oracle") \- Headers for oracle (version here) database clientlibs,
  * [os2units](<Os2Units.md> "Os2Units") \- Interfaces to various libraries available under OS/2 and eComStation
  * [palmunits](</index.php?title=palmunits&action=edit&redlink=1> "palmunits \(page does not exist\)") \- Palm OS SDK 4.0
  * [pasjpeg](</index.php?title=pasjpeg&action=edit&redlink=1> "pasjpeg \(page does not exist\)") \- A Pascal conversion (thus without dependancies) of the libjpeg library.
  * [paszlib](<paszlib.md> "paszlib") \- A Pascal conversion (thus without dependancies) of the standard zlib library.
  * [pcap](<pcap.md> "pcap") \- Headers for the Packet Capture library
  * [postgres](<postgres.md> "postgres") \- Headers for Postgres (version here) database clientlibs
  * [proj4](</index.php?title=proj4&action=edit&redlink=1> "proj4 \(page does not exist\)") \- Headers for Proj.4 a Cartographic Projections Library. See [Homepage](<http://trac.osgeo.org/proj/>)
  * [ptc](<ptc.md> "ptc") \- Headers for OpenPTC, a high-speed low-level graphics access library. See [Textmode IDE development](<Textmode_IDE_development.md> "Textmode IDE development")
  * [pthreads](</index.php?title=pthreads&action=edit&redlink=1> "pthreads \(page does not exist\)") \- Headers for pthreads unix threading libraries.
  * [pxlib](</index.php?title=pxlib&action=edit&redlink=1> "pxlib \(page does not exist\)") \- A library to read and write Paradox DB files
  * [regexpr](<Regexpr.md> "Regexpr") \- Regex (regular expression) engine
  * [rexx](<REXX.md> "REXX") \- Interface to REXX SAA headers allowing to use Pascal code in REXX scripts
  * [sdl](</index.php?title=sdl&action=edit&redlink=1> "sdl \(page does not exist\)") \- Simple DirectMedia Layer
  * [sndfile](<sndfile.md> "sndfile") \- An interface to the linux (?) libsndfile library.
  * [sqlite](<sqlite.md> "sqlite") \- Cross-platform C library that implements a self-contained, embeddable, zero- configuration SQL database engine. See [SQLite Homepage](<http://www.sqlite.org/>)
  * [svgalib](<svgalib.md> "svgalib") \- An interface to the SVGA graphics library (Unix).
  * [symbolic](</index.php?title=Symbolic&action=edit&redlink=1> "Symbolic \(page does not exist\)") \- Expression parser with minimal symbolic manipulation
  * [syslog](<syslog.md> "syslog") \- Provides an interface to the Unix system logger Daemon
  * [tcl](<tcl.md> "tcl") \- An interface to the tcl/tk interpreter.
  * [univint](<univint.md> "univint") \- Mac OS X interfaces (Carbon, CoreServices; CoreFoundation, CoreAudio, CoreGraphics, CoreType, CoreVideo, AudioUnits, ...).
  * [unixutil](</index.php?title=unixutil&action=edit&redlink=1> "unixutil \(page does not exist\)") \- Some old kylix wrapper. Delete?
  * [unzip](<unzip.md> "unzip") \- Routines for unzipping .zip files.
  * [users](</index.php?title=users&action=edit&redlink=1> "users \(page does not exist\)") \- Various routines to work with Unix users and groups
  * [utmp](<utmp.md> "utmp") \- Various routines to work with Unix /var/run/utmp, the unix login logfile
  * [uuid](</index.php?title=uuid&action=edit&redlink=1> "uuid \(page does not exist\)") \- A basic libuuid header.
  * [winceunits](</index.php?title=winceunits&action=edit&redlink=1> "winceunits \(page does not exist\)") \- WinCE API
  * [winunits-base](<Winunits-Base.md> "Winunits-Base") \- Additional windows units. Mostly Delphi compat (activex, comobj)
  * [winunits-jedi](</index.php?title=Winunits-Jedi&action=edit&redlink=1> "Winunits-Jedi \(page does not exist\)") \- Very complete winapi header translation from Jedi
  * [x11](<X11.md> "X11") \- Basic X Windows System (xlib) headers
  * [xforms](<XForms.md> "XForms") \- Basic XForms headers
  * [zlib](<ZLib.md> "ZLib") \- Basic interface to the zlib compression library.
  * [zorba](<Zorba.md> "Zorba") \- Zorba XQuery Processor. See [Homepage](<http://www.zorba-xquery.com>)
