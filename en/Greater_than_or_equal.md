# Greater than or equal

│ **English (en)** │    
****

>= 

The greater than or equal bigramm `>=` (consisting of [`>`, the greater than symbol](<Greater_than.md> "Greater than"), followed by [`=`, the equal symbol](<Equal.md> "Equal")) is used to compare two values in order to determine whether the value on the left side of the symbol is larger than or equal to that of the value to the right side of the symbol, and returns the [boolean](<Boolean.md> "Boolean") value of [true](<True.md> "True") or [false](<False.md> "False") as a result. 

The binary operator evaluates to [`true`](<false_and_true.md> "false and true"), if the left value is greater than or equal to the right value. 

In [ASCII](<ASCII.md> "ASCII"), the character code decimal `62` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `3E`) is defined to be `>` (Greater than), and the character code decimal `61` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `3D`) is defined to be `=` (equals sign).
