# Lazarus-ccr GitHub organization

## Introduction

There's a [Lazarus Code and Component Repository organization at GitHub](<https://github.com/lazarusccr>). If you want to host a repository there you need to contact one of the administrators: JuhaManninen or GetMem, all of them can be contacted in the Lazarus forum. 

Each repository can have one or multiple people working on it. When access as member of the organization is given to you, you can create as many repositories you need, and in the settings add one or more collaborators.
