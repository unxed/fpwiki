Portal:Mac

[![macOSlogo.png](https://wiki.freepascal.org/images/1/15/macOSlogo.png)](</File:macOSlogo.png>) This portal provides an overview of development for **Apple Silicon Macs and Intel Macs** running macOS (previously marketed as Mac OS X until 2012 and OS X until 2016) with Lazarus and Free Pascal. Development of macOS software is easy with Lazarus using the Cocoa (64 bit) widgetset. The Carbon (32 bit) widgetset is also available but only for 32 bit software and only up to macOS 10.14 Mojave. Apple removed the Carbon framework from macOS 10.15 Catalina (2019) - that operating system and future versions no longer run any 32 bit software. Other widgetsets like Qt are also supported, but their use requires additional effort. Free Pascal can also be used to develop software for PowerPC Macs, Mac OS Classic and older versions of macOS (before Tiger). Refer to the Legacy Information section at the bottom of this page.
