# End of Line

│ **English (en)** │  **[suomi (fi)](</End_of_Line/fi> "End of Line/fi")** │  **[русский (ru)](<../ru/End_of_Line.md> "End of Line/ru")** │    
****

` LineEnding` is end of line marker. This [constant](<Constant.md> "Constant") ([system unit](<System_unit.md> "System unit")) is used when writing end of lines to text files. In other words, it starts a new line. 

## End of line markers

(Better/also known as line ending characters) 

  * [Line feed](<Line_feed.md> "Line feed") (LF, #10 ): [Linux](<Linux.md> "Linux"), macOS, BSDs, Unix
  * [Carriage return](<Carriage_return.md> "Carriage return") \+ [Line feed](<Line_feed.md> "Line feed") (CRLF, #13#10): Microsoft Windows
  * [Carriage return](<Carriage_return.md> "Carriage return") (CR, #13): Mac OS Classic



macOS often accepts [Line feed](<Line_feed.md> "Line feed") and [Carriage return](<Carriage_return.md> "Carriage return").

  * [sLineBreak](<http://lazarus-ccr.sourceforge.net/docs/rtl/system/slinebreak.html> "doc:rtl/system/slinebreak.html") is an alias for LineEnding and is supplied for compatibility.
