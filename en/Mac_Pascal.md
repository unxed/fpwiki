# Mac Pascal

[![Logo OSX.png](https://wiki.freepascal.org/images/7/7a/Logo_OSX.png)](</File:Logo_OSX.png>)

This article applies to [Mac OS Classic](</Category:Mac_OS_Classic> "Category:Mac OS Classic") only.

See also: [Multiplatform Programming Guide](<Multiplatform_Programming_Guide.md> "Multiplatform Programming Guide")

│ **English (en)** │

**Mac Pascal** is a designation that was retrospectively assigned to Apple's [Object Pascal](<Object_Pascal.md> "Object Pascal"). 

Based on earlier foundations laid with [Lisa Pascal](<Lisa_Pascal.md> "Lisa Pascal") and [Clascal](<Clascal.md> "Clascal") a development team at Apple Computer led by [Larry Tesler](</index.php?title=Larry_Tesler&action=edit&redlink=1> "Larry Tesler \(page does not exist\)") developed an object-oriented version of the [Pascal](<Pascal.md> "Pascal") language in consultation with [Niklaus Wirth](<Niklaus_Wirth.md> "Niklaus Wirth"). The first version of this dialect, termed _Object Pascal_ , was released in 1985. 

Within short time Object Pascal became the premier development language for Mac OS Classic. Apple's Object Pascal syntax was also adopted by alternative IDEs for the Macintosh platform including [THINK Pascal](<THINK_Pascal.md> "THINK Pascal") and [Metrowerks Pascal](<https://macintoshgarden.org/author/metrowerks>). In 1989 concepts of Object Pascal were included in version 5.5 of [Turbo Pascal](<Turbo_Pascal.md> "Turbo Pascal"). 

Since then, [Object Pascal](<Object_Pascal.md> "Object Pascal") is a generic term for modern Pascal implementations allowing for OOP, and Apple's original implementation has been termed _Mac Pascal_. 

## Mac Pascal support in Free Pascal

Today, the Mac Pascal syntax is still supported by [Free Pascal](<Free_Pascal.md> "Free Pascal") if the [MACPAS](<Mode_MacPas.md> "Mode MacPas") mode is activated. This may be e.g. required if one wants to develop FPC programs for [Target MacOS](<Target_MacOS.md> "Target MacOS") and incorporate legacy code.
