# IDE Window: Codetools Directory Values

│ **English (en)** │

[![CodeTools Dir values 2 0 10.jpg](https://wiki.freepascal.org/images/4/43/CodeTools_Dir_values_2_0_10.jpg)](</File:CodeTools_Dir_values_2_0_10.jpg>)

The CodeTools Directory Values dialog is reached from the [Main Menu](<Main_menu.md> "Main menu") > [Source](<Main_menu.md> "Main menu") > [Unit Information](<IDE_Window__Unit_info.md> "IDE Window: Unit info") \- Show CodeTools Values button. 

This dialog shows the codetools values for a specific directory and how the values were created. 

At the top is the combobox to select a directory. 

At the left, in the middle, is a list of variables and values. 

At the right are the nodes and below are the current values of the selected node.
