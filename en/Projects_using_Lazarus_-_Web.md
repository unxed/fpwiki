## apiUi

[apiUi](<http://apiUi.org>) is free and [open source](<http://github.com/apiui/apiui>) software to virtualize and test SOAP and REST api services. It works with HTTP(s) but also with STOMP which means it can also be used with JMS and KAFKA. It is the only free API virtualization tool that uses formal contracts like Swagger, OpenApi and Cobol Copy Books to present a GUI with a form to edit the entire message. This allows end users to focus on functionality rather than language or technique, there is no need to know XML or JSON. When mocking, apiUi uses contract information to match inbound messages to the right operation. Your API virtualization solution is easy to install, easy to enhance and easy to share.

## Calendar Desk

Calendar Desk [Home Page](<http://calendardesk.com>) is a lightweight application that comes as an alternative to the integrated calendar offered by the operating system. Convenient calendar called with one click from the tray area. Convenient view of scheduled tasks on the calendar grid. Detailed view of planned tasks. Customizable interface with skins. Support of multi-language interface. Minimum computer resource requirements. Integration with **Google Calendar**. All scheduled tasks that you create on Google Calendar will be displayed on Calendar Desk.

## FoxWhois

[FoxWhois](<https://foxwhois.com/en/>) is a bulk domains checker. Does not require installation. There are free (foxwhois free) and paid (foxwhois pro) version. FoxWhois free scans .COM, .RU/.SU/.РФ domains for availability and whois data. FoxWhois pro has more advanced functionality. The software is multilingual (via i18n): currently supports English and Russian languages. 

## Open Sitemap Builder

[Open Sitemap Builder](<https://xn--90abhbolvbbfgb9aje4m.xn--p1ai/%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82/%D0%BF%D1%80%D0%BE%D1%87%D0%B5%D0%B5/open-sitemap-builder.html>) \- Cross-platform program for creating sitemap.xml sitemap without restrictions on the number of pages. ## Uniform Server

[Uniform Server](<http://www.uniformserver.com/>) is a free lightweight WAMP server solution for Windows. Less than 24MB, modular design, includes the latest versions of Apache2, Perl5, PHP (switch between PHP53..PHP71 etc), MySQL5 or MariaDB5, phpMyAdmin or Adminer4 Perl. No installation required! No registry dust! Just unpack and fire up! 

[![UniServer-WAMP-1.png](https://wiki.freepascal.org/images/e/e0/UniServer-WAMP-1.png)](</File:UniServer-WAMP-1.png>) [![UniServer-WAMP-2.png](https://wiki.freepascal.org/images/e/eb/UniServer-WAMP-2.png)](</File:UniServer-WAMP-2.png>)

## WandS

[WandS](<http://sourceforge.net/projects/wands/>) (Wake and Shutdown) is a program for webmasters or sysadmins for taking control of servers at datacenters. With WandS, you can shutdown or wake up any server or server group at any time through SSH or SMB. 

## WikiHelp

[WikiHelp](<http://www.ullihome.de/wiki/Softwareprojects/WikiHelp/index>) is a small tool that generates HTML pages from a Wiki. It downloads the content automatically and converts the WikiText pages into HTML. Most WikiText features are useable including images, tables and so on. 

## Xidel

A platform independent [command line tool](<http://videlibri.sourceforge.net/xidel.html>) to download webpages and extract data from them, using XPath 2 / XQuery expressions, CSS 3 selectors or custom pattern-matching templates.
