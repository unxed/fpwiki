# Graphical User Interface

│ **English (en)** │

Graphical user interface (GUI) is program that enables a person to communicate with electronic devices such as computers, smart phone, hand-held devices and other appliances through the use of symbols, visual metaphors, and pointing devices (such as a mouse, stylus, trackball, touchpad, a finger, or gesture ). 

The graphical user interface consists of user interface components, such as windows or forms (e.g.[TForm](<TForm.md> "TForm")), menus (e.g. [TMainMenu](<TMainMenu.md> "TMainMenu"), [TPopupMenu](<TPopupMenu.md> "TPopupMenu")), radio buttons (e.g. [TRadioButton](<TRadioButton.md> "TRadioButton"), [TRadioGroup](<TRadioGroup.md> "TRadioGroup")), check boxes (e.g. [TCheckBox](<TCheckBox.md> "TCheckBox"), [TCheckGroup](<TCheckGroup.md> "TCheckGroup")) and icons. 

The first graphical user interface programmed with Pascal was made for Apple Lisa in 1983 (see more [Lisa Pascal](<Lisa_Pascal.md> "Lisa Pascal") programming language). 

The Lazarus [development environment](<IDE.md> "IDE") is a good example of how to use the Graphical User Interface. More examples can be found in the [Projects using Lazarus](<Projects_using_Lazarus.md> "Projects using Lazarus") software category pages.
