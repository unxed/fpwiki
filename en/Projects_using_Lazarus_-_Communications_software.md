## InsideBlue

[InsideBlue](<https://github.com/eriklins/InsideBlue-BLE-Tool>) is an open-source PC cross-platform Bluetooth/LE (BLE) tool. It leverages [SimpleBLE library](<https://github.com/OpenBluetoothToolbox/SimpleBLE>) with [Pascal bindings](<https://github.com/eriklins/Pascal-Bindings-For-SimpleBLE-Library>) to access the PC/laptop built-in Bluetooth/LE controller. InsideBlue supports scanning for BLE peripherals and shows device information and BLE advert payload with known Bluetooth assigned UUID numbers. Filtering for peripherals based on BLE device name, mac address or RSSI value is supported. After connecting to a peripheral its GATT table is queried and services/characteristics/descriptors are displayed with known Bluetooth assigned UUID numbers and it allows to read/write/notify/indicate GATT characteristics. If a known BLE virtual serial port (VSP) service is being found, it's possible to fire up a terminal window and read/write data over the VSP port.

## Jubarte

[Jubarte](<https://sites.google.com/site/cticmg/software/jubarte>) aims to create a complete application suite to calculate and analyse the viability of telecommunication links. Jubarte is able to calculate links using Radio, Optical Fiber and Satellites, in the newer versions capabilities to calculate auxiliary systems is being added. Jubarte is being developped in Lazarus enviroment and exist binaries for Windows, Linux and macOS.

[MUTerm 0.1.1](<http://mehmetulukaya.wordpress.com/2012/09/18/muterm-yazilimi-yuklenmeye-hazir/>) MUTerm is a Com Port communication tool for external devices like as Modbus RTU , ASCII etc. Also you can write your communication routine with pascal script. ## P.SEN

[P.SEN](<https://sourceforge.net/projects/psen/>) is a utility to allow sending and receiving TCP and UDP packets and is available for Windows and Linux. It’s designed to be very easy to use while still providing enough features for power users to do what they need. It is completely free (no ads / no bundleware) and opensource. Some knowledge of a basic network protocols is a prerequisite to using it. Beyond that, P.SEN was designed to be very easy to use.

## Titos Terminal

[Tito's Terminal](<https://github.com/t-edson/Tito-s-Terminal>) GUI Terminal with syntax highlighting and automation for telnet, and ssh. 

This terminal can be used like a Telnet, SSH, and Serial client. and with any console program. It includes a text panel, used to send commands. 

[![TT1.png](https://wiki.freepascal.org/images/9/9f/TT1.png)](</File:TT1.png>)

The terminal screen, works like a VT100 terminal, but only implements the basic sequences. The screen width is not limited to the VT100 width, but it can be extended much more. The terminal can be configured to detect and highlight the prompt. A visual file manager is included to work with Telnet and SSH connections, and makes easy to work with files. A remote editor is also included ant let us edit small files in a telnet or ssh session, using the shell commands to edit files. Tito's Terminal have an special editor for automation using macros in a similar language of the client TeraTerm. The program is very flexible, including several options for configure the appareance and behaviour. 

## Transmission Remote GUI

[Transmission Remote GUI](<http://transgui.sourceforge.net//>) is a feature rich cross platform front-end to remotely control a Transmission Bit-Torrent client daemon via its RPC protocol. Transmission Remote GUI is faster and has more functionality than the build-in Transmission web interface.
