# PascalScript

**PascalScripts** are script programs that are written in [Pascal](<Pascal.md> "Pascal"). Scripting with Pascal is e.g. supported by the macro system of of [Lazarus](<Lazarus.md> "Lazarus"). Additionally, PascalScripts may be executed directly by the shell with help of the [InstantFPC](<InstantFPC.md> "InstantFPC") tool. 

PascalScripts are also supported by several third party applications, e.g. [Inno Setup](<Inno_Setup.md> "Inno Setup"). 

## Implementations

  * [Pascal Script](<Pascal_Script.md> "Pascal Script"), an ObjectPascal/Delphi/Lazarus compatible interpreter with bytecode compiler developed by RemObjects.
  * [InstantFPC](<InstantFPC.md> "InstantFPC"), a framework to directly start FPC scripts from the command shell
  * [paxCompiler](</index.php?title=paxCompiler&action=edit&redlink=1> "paxCompiler \(page does not exist\)"), an embeddable compiler for [Object Pascal](<Object_Pascal.md> "Object Pascal") and other languages.
  * [FastScript](<FastScript.md> "FastScript"), a commercial cross-platform, multi-language scripting engine
