# Integrating Javascript Engines with Pascal

## Overview

This page describes integrating Javascript engines with Free Pascal. 

## ChakraCore

  * [ChakraCore](<https://github.com/chakra-core/ChakraCore>) is an open source Javascript engine with a C API.
  * [chakracore-delphi](<https://github.com/tondrej/chakracore-delphi>) is a Delphi and Free Pascal binding for ChakraCore.



## QuickJS

  * [QuickJS](<https://bellard.org/quickjs/>) is a small and embeddable Javascript engine.
  * [QuickJS-Pascal](<https://github.com/Coldzer0/QuickJS-Pascal>) is a Free Pascal and Delphi binding for QuickJS.
