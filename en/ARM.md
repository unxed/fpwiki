ARM is a processor architecture implemented in various (often incompatible) chipsets and devices running various operating systems. 

## Embedded Libraries

There are some libraries related to the embedded target providing access to the hardware most ARM microcontrollers provide. If you run a full Linux on your ARM processor, it's best to use the Linux' way to handle the hardware - see [Raspberry Pi#Accessing external hardware](<Raspberry_Pi.md> "Raspberry Pi") for more information. 

  * [Pascal port of the STM32F7xx_HAL](<https://github.com/Laksen/fp-stm32f7xx_hal>)
  * [Realtime OS for embedded systems](<https://github.com/Laksen/fp-rtos>), currently supports ARMv4T, ARMv6, AVR
  * [Project Template for STM32 MCU](<https://github.com/Turro75/stm32lazarustemplate>)
