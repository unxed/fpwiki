# Less than or equal

│ **English (en)** │

<= 

The less than or equal bigramm `<=` (consisting of [`<`, the less than symbol](<Less_than.md> "Less than"), followed by [`=`, the equal symbol](<Equal.md> "Equal")) is used to compare two values in order to determine whether the value on the left side of the symbol is smaller than or equal to that of the value to the right side of the symbol, and returns the [boolean](<Boolean.md> "Boolean") value of [true](<True.md> "True") or [false](<False.md> "False") as a result. 

The binary operator evaluates to [`true`](<false_and_true.md> "false and true"), if the left value is less than or equal to the right value. 

In [ASCII](<ASCII.md> "ASCII"), the character code decimal `60` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `3C`) is defined to be `<` (Less than), and the character code decimal `61` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `3D`) is defined to be `=` (equals sign).
