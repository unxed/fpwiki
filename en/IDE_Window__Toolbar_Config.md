# IDE Window: Toolbar Config

[![IDE-options-Environment-Toolbar-Configuration.png](https://wiki.freepascal.org/images/5/54/IDE-options-Environment-Toolbar-Configuration.png)](</File:IDE-options-Environment-Toolbar-Configuration.png>)

The **Toolbar Configuration** dialog is used for two toolbars: 

[![](https://wiki.freepascal.org/images/9/9e/Main-IDE-Coolbar.png)](</File:Main-IDE-Coolbar.png>)

Main IDE Coolbar

[![](https://wiki.freepascal.org/images/2/28/Source-Editor-Toolbar.png)](</File:Source-Editor-Toolbar.png>)

Source Editor Toolbar

  


  * The Main IDE Coolbar is shown on two lines in the top left corner of the IDE. It has a number of buttons by default: 
    * Line 1: "New Pascal Unit", "New Form", "Open...", "Save", "Save All", "Toggle Form/Unit" and "Desktops".
    * Line 2: "View Project Units", "View Project Forms", "Change Build Mode", "Run with Debug", "Pause", "Stop", "Step over", "Step into", "Step out". The image above also shows the "Run without debugging" green triangle with the red cross.


  * The Source Editor Toolbar is shown above source editor, it has few buttons by default: "Configure Toolbar", "Jump Back", "Jump Forward".



## Controls

Expand a category in the left pane of the **Toolbar Configuration** dialog, and then you may select a new item and then use the **Move right** button to add it to the toolbar list in the right pane. 

You may use the **Move left** button to select an existing item on the toolbar and remove it. 

You may rearrange Toolbar items with **Move Up** and **Move Down** buttons. 

Hint: to append an item at the end, clear selection first.
