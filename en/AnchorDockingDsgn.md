# AnchorDockingDsgn

This is the package that provides a docked IDE instead of the default "separate windows" look of the Lazarus IDE. 

Thus it'll look more like the RAD Studio™ as shown in the following screenshot: 

[![lazarus docked ide.PNG](https://wiki.freepascal.org/images/7/79/lazarus_docked_ide.PNG)](</File:lazarus_docked_ide.PNG>)

To dock/undock a window, you have to enable option "Show headers". 

For installation and other information click [here](<Anchor_Docking.md> "Anchor Docking").
