# Less than

****

<

The less than symbol, _**<**_ is used to compare whether the value on the left side of the symbol is smaller than that of the value to the right side of the symbol, and returns the [boolean](<Boolean.md> "Boolean") value of [true](<True.md> "True") or [false](<False.md> "False") as a result. 

In [ASCII](<ASCII.md> "ASCII"), the character code decimal `60` (or [hexadecimal](<Hexadecimal.md> "Hexadecimal") `3C`) is defined to be `<` (Less than).
