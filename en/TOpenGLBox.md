### About

_TOpenGLBox_ is a barebones OpenGL component. It provides an OpenGL rendering area to be used with forms designed in Lazarus. 

Its main caracteristics are : 

  * simple.
  * small.
  * works in Linux (gtk1) and Windows.



The download contains the component, an installation package and a demo application, that illustrates the features of the component.

### Installation

  * Uncompress the archive somewhere (preferably in your Lazarus' _components_ folder).
  * Add the component to the component library by opening the package file, pressing _compile_ and then _install_.
