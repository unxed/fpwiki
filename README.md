# Free Pascal Wiki (Markdown mirror)

English and Russian article pages from [wiki.freepascal.org](https://wiki.freepascal.org/), restored from the [Wayback Machine](https://web.archive.org/) after the live wiki became unreachable behind a broken Anubis challenge.

## Contents

| Path | Language | Pages |
|------|----------|------:|
| `en/` | English | 2766 |
| `ru/` | Russian | 645 |

Subpages become nested folders (e.g. `en/ZSeries/Part_4.md`).

**Not included:** Talk/discussion pages, user pages, templates, categories, files/images, and other non-article namespaces. Pages that never had a usable Wayback capture are also omitted.

## Editing

This repo is a PR-friendly documentation vault. Fix typos, update outdated notes, or improve structure via pull requests.

Internal wiki links are rewritten to relative `.md` paths where possible. Each page ends with a Wayback source link for provenance.

## Provenance

Pages were taken from the latest Wayback captures that still contain real MediaWiki article HTML (typically through early/mid‑2025), skipping Anubis interstitial responses.
