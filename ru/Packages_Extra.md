# Packages Extra

│ **[English (en)](<../en/Packages_Extra.md>)** │  **русский (ru)** │

Обратите внимание, что начиная с версии 2.2.2, больше не будут доступны основные и дополнительные пакеты, потому что все они были объединены в packages/subdir. 

Новый список пакетов смотрите [здесь](<../en/Package_List.md> "Package List")

  * [OpenGL](<../en/OpenGL.md> "OpenGL") интерфейс OpenGL (Open Graphics Library).
  * [REXX](<../en/REXX.md> "REXX") интерфейс для REXX SAA, позволяет использовать Pascal код в REXX скриптах
  * [Os2Units](<../en/Os2Units.md> "Os2Units") интерфейсы для различных библиотек, доступных только под OS/2 и eComStation
