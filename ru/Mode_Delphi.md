# Mode Delphi

│ **[English (en)](<../en/Mode_Delphi.md>)** │  **русский (ru)** │

Данный режим предоставлен для совместимости с компилятором [Delphi](</index.php?title=Delphi/ru&action=edit&redlink=1> "Delphi/ru \(page does not exist\)") от компании Embarcadero с целью упрощения портирования существующих исходных файлов на Free Pascal. Для этого вам необходимо включить этот режим директивой **${mode Delphi}** в исходном файле или с помощью опции **-Mdelphi** в командной строке компилятора.
