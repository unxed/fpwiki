# H2Pas

│ **[English (en)](<../en/H2Pas.md>)** │  **русский (ru)** │

Взято из [FreePascal User's Manual](<ftp://ftp.freepascal.org/pub/fpc/docs-pdf/user.pdf>): 

**h2pas** пытается конвертировать заголовочный файл языка C в модуль Pascal. Он может обработать большинство конструкций языка C, которые найдёт в заголовочном файле и пытается перевести их в соответствующие конструкции Pascal. Смотрите документацию для полного описания того, что конвертор может обработать. Модуль с объявлениями Pascal потом может быть использован для доступа к коду, написанному на C. 

Программа h2pas осуществляет вывод в файл с тем-же именем, что и заголовочный файл языка C, который был использован на входе, но с расширением **.pp**. Выходной файл, создаваемый h2pas, может быть настроен несколькими способами путём использования множества опций. 

Имеется графический интерфейс для h2pas, который называется [H2Paswizard](<H2Paswizard.md> "H2Paswizard/ru").
