# Smallint

│ **[English (en)](<../en/Smallint.md>)** │  **русский (ru)** │

Тип **Smallint** является знаковым целым типом, поддерживающим значения в диапазоне от -32768 до 32767. Для переменных этого типа отводится 2 байта (16 бит).
