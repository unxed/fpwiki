# Mode GPC

│ **[English (en)](<../en/Mode_GPC.md>)** │  **русский (ru)** │

**Режим GPC** был [режимом компилятора](</index.php?title=Compiler_Mode/ru&action=edit&redlink=1> "Compiler Mode/ru \(page does not exist\)"), с помощью которого [Free Pascal](<FPC.md> "FPC/ru") пытался компилировать только допустимый код [GNU Pascal](</index.php?title=GNU_Pascal/ru&action=edit&redlink=1> "GNU Pascal/ru \(page does not exist\)"). Данный режим удален из компилятора Free Pascal начиная с версии 2.2.
