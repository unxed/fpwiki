# Int

│ **[English (en)](<../en/Int.md> "Int")** │  **русский (ru)** │    
****

Функция **Int** возвращает целую часть аргумента. X - выражение [вещественного](<Real.md> "Real/ru") типа. Результатом является целая часть X, округленная до нуля. 

Объявление 
    
    
    function Int(X: Real): Real;
