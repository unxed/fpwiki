# Standard tab

│ **[English (en)](<../en/Standard_tab.md>)** │  **русский (ru)** │

Вкладка **Standard** [палитры компонентов](<Component_Palette.md> "Component Palette/ru"), содержит список элементарных компонентов, которые могут быть использованы на форме.

[![tpopupmenu.png](https://wiki.freepascal.org/images/5/5d/tpopupmenu.png)](</File:tpopupmenu.png>) | [TPopupMenu](<TPopupMenu.md> "TPopupMenu/ru") | всплывающее меню   
[![tbutton.png](https://wiki.freepascal.org/images/b/b2/tbutton.png)](</File:tbutton.png>) | [TButton](<TButton.md> "TButton/ru") | кнопка с текстом   
[![tlabel.png](https://wiki.freepascal.org/images/3/3a/tlabel.png)](</File:tlabel.png>) | [TLabel](<TLabel.md> "TLabel/ru") | надпись

[![tcheckbox.png](https://wiki.freepascal.org/images/3/3c/tcheckbox.png)](</File:tcheckbox.png>) | [TCheckBox](<TCheckBox.md> "TCheckBox/ru") | флажок, может отображаться в одном из двух состояний (установлен\снят)   
[![tradiobutton.png](https://wiki.freepascal.org/images/e/ef/tradiobutton.png)](</File:tradiobutton.png>) | [TRadioButton](<../en/TRadioButton.md> "TRadioButton") | переключатель, предназначен для выбора одного переключателя из ряда возможных   
[![tlistbox.png](https://wiki.freepascal.org/images/7/7f/tlistbox.png)](</File:tlistbox.png>) | [TListBox](<../en/TListBox.md> "TListBox") | список строк, одна из которых может быть выбрана

[![tscrollbar.png](https://wiki.freepascal.org/images/0/05/tscrollbar.png)](</File:tscrollbar.png>) | [TScrollBar](<../en/TScrollBar.md> "TScrollBar") | полоса прокрутки   
[![tgroupbox.png](https://wiki.freepascal.org/images/1/18/tgroupbox.png)](</File:tgroupbox.png>) | [TGroupBox](<TGroupBox.md> "TGroupBox/ru") | контейнер, позволяющий объединить элементы управления в группы   
[![tradiogroup.png](https://wiki.freepascal.org/images/b/b8/tradiogroup.png)](</File:tradiogroup.png>) | [TRadioGroup](<TRadioGroup.md> "TRadioGroup/ru") | группа переключателей. Похож на TGroupBox с интегрированными TRadioButton   
[![tcheckgroup.png](https://wiki.freepascal.org/images/0/0b/tcheckgroup.png)](</File:tcheckgroup.png>) | [TCheckGroup](<TCheckGroup.md> "TCheckGroup/ru") | группа флажков. Похож на TGroupBox с интегрированными TCheckBox.   
[![tpanel.png](https://wiki.freepascal.org/images/7/7d/tpanel.png)](</File:tpanel.png>) | [TPanel](<TPanel.md> "TPanel/ru") | визуальный контейнер для других элементов управления   
[![tframe.png](https://wiki.freepascal.org/images/4/4d/tframe.png)](</File:tframe.png>) | [TFrame](<TFrame.md> "TFrame/ru") | контейнер для компонентов, который может быть размещен на форме или внутри другого контейнера.   
[![tactionlist.png](https://wiki.freepascal.org/images/4/4b/tactionlist.png)](</File:tactionlist.png>) | [TActionList](<TActionList.md> "TActionList/ru") | список действий ([TAction](</index.php?title=TAction/ru&action=edit&redlink=1> "TAction/ru \(page does not exist\)")) для централизации обработки событий меню/мыши/клавиатуры
