# NaN

│ **[English (en)](<../en/NaN.md> "NaN")** │  **[suomi (fi)](</NaN/fi> "NaN/fi")** │  **русский (ru)** │    
****

NaN (нечисло) - числовой тип данных, значение которого является неопределенным или непредставимым (не соответствует ни одному из стандартных типов). Эти значения возникают при выполнении операций, которые имеют неопределенный числовой результат. **NaN не то же самое, что бесконечность**. 
    
    
    program Project1;
    
    begin
      Writeln (0/0);
      Readln;
    end.
