Задание по программированию

1H - Programming Assignment (author: Tao Yue, state: unchanged) 

  
Теперь вы знаете, как использовать переменные и менять их значения. Вы готовы к вашему первому заданию по программированию? 

Но есть одна небольшая проблема: вы еще не научились отображать данные на экране! Как вы узнаете, работает ваша программа или нет, если вся эта информация продолжает храниться в памяти и не отображается на экране? 

Итак, для начала - вот вам фрагмент из нескольких следующих уроков. Для отображения данных используйте: 
    
    
    writeln (argument_list);
    

Список аргументов составляется из строк или имён переменных, разделенных запятыми. Например: 
    
    
    writeln ('Sum = ', sum);
    

**Вот задание по программированию для главы 1:**

Найдите сумму и среднее значение пяти целых чисел. Сумма должна быть целым числом, а среднее должно быть вещественным. Эти пять чисел: 45, 7, 68, 2 и 34. 

Используйте константу для указания количества целых чисел, обрабатываемых программой, т.е. объявите константу, имеющую значение 5. 

Потом всё это распечатайте! Вывод на экран должен выглядеть примерно так: 
    
    
    Number of integers = 5
    Number1 = 45
    Number2 = 7
    Number3 = 68
    Number4 = 2
    Number5 = 34
    Sum = 156
    Average = 3.1200000000E+01
    

Как вы можете видеть, по умолчанию метод вывода для вещественных чисел - научная нотация. Глава 2 объяснит вам, как отформатировать их для отображения с фиксированной десятичной точкой.
