-

  


  


  


  
Символ _**-**_ (читается "минус") используется для вычитания одного числа из другого (_число_слева_ минус _число_справа_); результатом будет число. Если число справа больше числа слева, то в результате получится отрицательное число. 
    
    
     A := 1 - 3; // -> A = -2
