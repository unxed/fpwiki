+

  


  


  


  
Символ _**+**_ (читается "плюс") используется для: 

  * сложения двух чисел - в результате будет число
  * или для конкатенации (соединения) двух строк - в результате будет строка.


    
    
    A := 1 + 3; // -> A = 4
    B := 'две строки ' + 'соединены'; // -> B = 'две строки соединены'
