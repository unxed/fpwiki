## Параметры

## Всплывающее меню

Учтите, что некоторые пункты появляются только тогда, когда происходит щелчок правой кнопкой мыши по файлу или зависимости. 

### Выключить I18N для lfm

Выберете для выключения автоматического обновления .po-файла для строк файла LFM. Подробнее смотрите в разделе [Параметры проекта](<IDE_Window__Project_Options.md> "IDE Window: Project Options/ru"). 

### Открыть загруженный пакет

Открывает редактор пакетов данной зависимости. 

### Удалить зависимость

Удаляет выбранную зависимость 

### Переместить зависимость вверх

Изменяет порядок зависимостей. Порядок используется средой разработки, но вы не должны полагаться на неё. Данная опция присутствует главным образом по эстетическим соображениям. 

### Переместить зависимость вниз

Аналогично предыдущему действию, но перемещает на одну позицию вниз. 

### Сохранить как имя файла по умолчанию для этой зависимости

Сохраняет относительное имя .lpk-файла в файле проекта (.lpi) для использования по умолчанию. Когда проект скопирован и открыт на другом компьютере, среда разработки осуществляет поиск всех необходимых пакетов. В качестве последнего значения по умолчанию используется это имя. 

[![SetDefaultPkDependency1.png](https://wiki.freepascal.org/images/c/c8/SetDefaultPkDependency1.png)](</File:SetDefaultPkDependency1.png>)

### Сохранить как предпочтительное имя файла для этой зависимости

Сохраняет относительное имя .lpk-файла в файле проекта (.lpi) для использования в качестве предпочтительного. Когда проект открыт среда разработки открывает данный файл пакета. Если пакет с тем же именем уже открыт, то он будет замене предпочтительным файлом. Данная функция существует, начиная с версии Lazarus 0.9.29. 

### Очистить выбранное имя файла зависимости

Данная опция очищает имя файла, используемое по умолчанию, для этой зависимости, установленное опцией 'Сохранить имя файла зависимости', описанной выше. 

### Удалить несуществующие файлы

Удаляет все файлы из проекта, которые не существуют в системе. Данная функция существует, начиная с версии Lazarus 0.9.29.
