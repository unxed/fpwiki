# Приложения

## 3D Image Commander

[3D Image Commander](<http://www.binerus.com>) позволяет дизайнерам добавить разнообразные полностью настраиваемые 3D-эффекты на свои фотографии и изображения. Это может быть сделано также в режиме реального времени. Программа проста в использовании и включает в себя только необходимые функции. Эта программа построена с использованием FPC, Lazarus и [DXScene library](<http://www.ksdev.com>). 

[![3D Image Commander](https://wiki.freepascal.org/images/8/88/imagecommander3d_screen.jpeg)](</File:imagecommander3d_screen.jpeg> "3D Image Commander")

## Advanced Password Generator

[Advanced Password Generator](<https://sourceforge.net/projects/apwg/>) это легкий инструмент генератор паролей для защиты вашей безопасности со случайно сгенерированным паролем. Он работает на Windows, и Linux. Не требует установки. Этот инструмент имеет версию для графического интерфейса и командной строки. Версия для командной строки идеально подходит для сценариев. 

[![scrnsht1.png](https://wiki.freepascal.org/images/d/db/scrnsht1.png)](</File:scrnsht1.png>)

## Ancestromania

[Ancestromania](<http://genealogie.liberlog.fr/Family-trees>) Полностью совместим с LGPL. Дружественно к пользователю. Вы можете импортировать и экспортировать в Gedcom. Вы можете экспортировать в Geneanet и на веб-сайт. Это большое графическое дерево, с быстрыми классическими деревьями. Есть много последующих документов. 

[Ancestroweb](<http://genealogie.liberlog.fr/Family-trees>) создано с помощью [static genealogy's web site](<http://matthieu.giroux.free.fr/genealogie/default.htm>). Это французская программа, но может быть легко переведена. Она является частью Ancestromania. 

[![Ancestromania.jpg](https://wiki.freepascal.org/images/e/e5/Ancestromania.jpg)](</File:Ancestromania.jpg>)[![2012-04 Ancestroweb.jpg](https://wiki.freepascal.org/images/1/17/2012-04_Ancestroweb.jpg)](</File:2012-04_Ancestroweb.jpg>)[![2012-05 Ancestroweb carte.jpg](https://wiki.freepascal.org/images/2/28/2012-05_Ancestroweb_carte.jpg)](</File:2012-05_Ancestroweb_carte.jpg>)

## ApplePi-Baker

[ApplePi-Baker](<http://www.tweaking4all.com/hardware/raspberry-pi/macosx-apple-pi-baker/>) является небольшой программой для Mac OS X для пользователей Raspberry Pi. Она позволяет записать образы IMG с SD-карты, подготовить SD-карту для использования Noobs (see: [Raspberry Pi Downloads page for details](<http://www.raspberrypi.org/downloads>), и создавать резервные копии SD-карты в IMG файл. Программа автоматически определяет SD-карты и SD-считыватели и была оптимизирована для совместимости с [retinize](<http://retinizer.mikelpr.com/>) (обеспечивает для не-Retina приложений внешний вид намного лучше на экранах Retina). 

[![applepi-baker13.png](https://wiki.freepascal.org/images/a/a6/applepi-baker13.png)](</File:applepi-baker13.png>)

## AWGG

[AWGG](<https://sites.google.com/site/awggproject>) это кросс-платформенный и многоязычной менеджер загрузки, который использует самые популярные программные движки (консольные), такие как wget, aria2, cURL и Axel, AWGG представляет собой интерфейс для них. Является многопоточным, портативным и простым, включает возможность программирования, множественные очереди, мониторинг буфера обмена, сайт-граббер и может быть интегрирована в Firefox с плагином FlashGot плагин, и Chrome плагин Simple Get. 

[![Pantallazo-AWGG 0.3.0 ALPHA BUILD 2002.png](https://wiki.freepascal.org/images/f/fa/Pantallazo-AWGG_0.3.0_ALPHA_BUILD_2002.png)](</File:Pantallazo-AWGG_0.3.0_ALPHA_BUILD_2002.png>) [![Pantallazo-Configuracion.png](https://wiki.freepascal.org/images/f/f4/Pantallazo-Configuracion.png)](</File:Pantallazo-Configuracion.png>) [![Pantallazo-Nueva descarga.png](https://wiki.freepascal.org/images/4/4b/Pantallazo-Nueva_descarga.png)](</File:Pantallazo-Nueva_descarga.png>)

## BioTray

[BioTray by FIENS](<https://sites.google.com/site/biotray/>), Ваш биоритм в трее. Биоритмы означают ритмы жизни. Наша жизнь управляется эмоциональным, интеллектуальным и физическим ритмами, которые начинаются при нашем рождении. Вы увидите в вашем трее 4 новых иконки. К ним относятся: эмоциональный, интеллектуальный, физический и интуитивный доступный значок. Как более значок заполнен, насколько велика ваша сила. На Windows, Linux и Mac OS X.

## Boblight Config Maker

[Boblight Config Maker](<http://www.tweaking4all.com/home-theatre/xbmc/boblight-config-maker/>) Автор создал это приложение, чтобы создавать конфигурационные файлы Open Source для AmibLight, называется Boblight. 

Boblight работает на коробкой XBMC, который соединен с Arduino по USB для управления светодиодами за телевизором. 

Это приложение позволяет настроить количество светодиодов и позиции светодиодов за телевизором для эффекта Ambilight. Программа свободно доступна для macOS, Windows и Linux и может быть загружена с [Tweaking4All](<http://www.tweaking4all.com/home-theatre/xbmc/boblight-config-maker/>) где вы также найдете "руководство". 

[![boblight config maker windows.jpg](https://wiki.freepascal.org/images/a/a0/boblight_config_maker_windows.jpg)](</File:boblight_config_maker_windows.jpg>)

## SimThyr

[SimThyr](<http://simthyr.sourceforge.net/>) представляет собой программу для моделирования связи и работы щитовидной железы и гипофиза, которая основана на параметрической изоморфной модели. Цель работы состоит в том, чтобы лучше понять динамику гомеостаза щитовидной железы. Алгоритмы, заложенные в программу, охватывают исследования, включая разработку гипотез, а также обучение студентов в области биологии и медицины, медсестер и пациентов. SimThyr используются для различных научных проектов. 

[![SimThyr for Mac OS X](https://wiki.freepascal.org/images/7/75/Simthyr_mac_os_x_leopard.png)](</File:Simthyr_mac_os_x_leopard.png> "SimThyr for Mac OS X") [![SimThyr for Linux](https://wiki.freepascal.org/images/a/a6/pr.simthyr_suse_linux_11.jpg)](</File:pr.simthyr_suse_linux_11.jpg> "SimThyr for Linux") [![SimThyr for Windows](https://wiki.freepascal.org/images/c/ca/SimThyr_Win7.png)](</File:SimThyr_Win7.png> "SimThyr for Windows")

## Virtual Magnifying Glass (экранная лупа)

Virtual Magnifying Glass - бесплатная экранная лупа с открытым исходным кодом. Работает под Windows, FreeBSD и Linux. Лупа настраиваемая проста в использовании. Программа может похвастаться более чем 170 000 загрузок и историей, длиной более пяти лет. 

[![Magnifier 3 2.png](https://wiki.freepascal.org/images/9/93/Magnifier_3_2.png)](</File:Magnifier_3_2.png>)

## FoxWhois: whois клиент для массовой проверки доменных имен

[FoxWhois](<https://foxwhois.com/>) (Extended WHoIs Client for bulk checking). Бесплатная версия проприетарного продукта FoxWhois free позволяет проверять большие списки доменных имен по протоколу whois на занятость и другие параметры. С помощью программы удообно подбирать свободное доменное имя. Платная версия включает дополнительные параметры (не whois), а также возможность в автоматическим режиме регистрировать домен непосредственно из самой программы FoxWhois. 

Скачать FoxWhois free ( <https://foxwhois.com/ru/free/download> ) 

[![whic free.png](https://wiki.freepascal.org/images/f/f8/whic_free.png)](</File:whic_free.png>)

## Woodland Potential Calculator

Комиссия по лесному хозяйству Великобритании и организация "Natural England" заказали специальный инструмент работы с лесным фондом страны. Программа предназначена для сбора и представления данных по лесам, позволяет вести расчеты по увеличению площади лесов по всей Англии. [Подробнее.](<http://www.michellcomputing.co.uk/woodlandcalc.html>)

Проект полностью написан на FreePascal с использованием Lazarus, встроенных библиотек LCL и Graphics32. WoodlandCalc выпущен под лицензией LGPL v2 с открытым исходным кодом и свободно доступен для загрузки из SourceForge. 

Приложение: 

  * <http://sourceforge.net/projects/woodlandcalc/files/latest/download>
