# Equal

│ **[English (en)](<../en/Equal.md>)** │  **русский (ru)** │

=

  
Символ = (читается "равно") используется для проверки равенства двух значений. В отличие от других языков программирования, этот символ не используется для присваивания значения - для этого вам необходимо использовать символ [:=](<Becomes.md> "Becomes/ru") (символ [двоеточия](<Colon.md> "Colon/ru") с расположенным за ним символом равенства, который читается как "[присвоить](<Becomes.md> "Becomes/ru")").
