# Важно

Вы должны [настроить отладчик](<Debugger_Setup.md> "Debugger Setup/ru") и запустить проект для его отладки. Только тогда это окно будет полезно. 

# Потоки

[![Threads Dlg.png](https://wiki.freepascal.org/images/f/fb/Threads_Dlg.png)](</File:Threads_Dlg.png>)

Отображает список всех потоков в вашем приложении. Source и function ссылаются на текущую точку выполнения в каждом потоке. 

Список обновляется только тогда, когда приложения приостановлены (например, достигли точки останова). 

Current (Текущий)
    изменить поток, используемый окном [ Callstack](<IDE_Window__Call_Stack.md> "IDE Window: Call Stack/ru"), [ Watch](<IDE_Window__Watch_list.md> "IDE Window: Watch list/ru") и [ Locals](<IDE_Window__Local_Variables.md> "IDE Window: Local Variables/ru").

Goto (Перейти к)
    открывает точку выполнения выбранного потока в редакторе исходного кода. Только если доступен исходник
