## О программе

H2Paswizard - это графический интерфейс пользователя, обёртка вокруг инструмента [H2Pas/ru](<H2Pas.md> "H2Pas/ru"), используемого для конвертации заголовочных файлов языка C в код Pascal.

## Установка

Этот инструмент доступен как стандартный набор в Lazarus Components. 

## Как использовать

  
[![h2paswizard.PNG](https://wiki.freepascal.org/images/c/c5/h2paswizard.PNG)](</File:h2paswizard.PNG>)   
  


  * Установите пакет H2Pas в IDE Lazarus.
  * Выберите пункт меню Tools -> H2Pas...
  * Щёлкните **Add ".h" files...** для выбора файлов **.h** для конвертации.
  * Настройте опции конвертации на вкладке **h2pas Options**
  * Настройте любые другие желаемые опции.
  * Нажмите кнопку **Run h2pas** для конвертации выбранных заголовочных файлов.
