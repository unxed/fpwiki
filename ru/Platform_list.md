## Поддерживаемые архитектуры

  * I386
  * PowerPC
  * Sparc (начало разработки, выполнена большая часть работы)
  * AMD64 (x86-64)
  * PowerPC64
  * [ARM](<../en/ARM.md> "ARM")
  * m68k (только FPC 1.0.x; начиная с версии 2.x поддержка окончена)



## Другие архитектуры и их статус

  * iA64: не собирается компилятор, имеются только некоторые базовые модули компилятора
  * Alpha: не собирается компилятор, имеются только некоторые базовые модули компилятора
  * [MIPS](<../en/MIPS_port.md> "MIPS port"): не собирается компилятор, имеются только некоторые базовые модули компилятора
  * [AVR](<../en/AVR.md> "AVR"): отдельная ветка разработки



## Поддерживаемые системы для i386

  * [GO32V2](<../en/GO32V2.md> "GO32V2") DOS расширение
  * Linux для i386
  * [OS/2](<../en/Target_OS2.md> "Target OS2") / eComStation
  * Win32 для i386
  * [FreeBSD](<../en/FreeBSD.md> "FreeBSD")/ELF для i386
  * SunOS/ELF для i386 (в разработке)
  * [BeOS port](<../en/BeOS_port.md> "BeOS port") для i386 (в разработке)
  * NetBSD для i386 (в разработке, в настоящее время поддерживается меньше)
  * [Netware](<../en/Netware.md> "Netware") для i386 (clib и libc)
  * WDOSX DOS расширение
  * OpenBSD для i386 (в разработке, в настоящее время поддерживается меньше)
  * OS/2 через EMX (соответствует системе OS/2 в версии 1.0.x и ниже; RTL на основе библиотек времени выполнения EMX позволяет создавать приложения DOS с расширением EMX; в настоящее время не полностью совместимы)
  * Watcom совместимый с DOS расширением
  * [Target Darwin](<../en/Target_Darwin.md> "Target Darwin") (Mac OS X) для i386 (2.1.x и выше)
  * [BeOS/Zeta/Haiku](<http://sourceforge.net/projects/befpc/>) для i386
  * [Target NativeNT](<../en/Target_NativeNT.md> "Target NativeNT") для i386 (в разработке, ожидается завершение)



## Поддерживаемые системы для SPARC

  * [SunOS/ELF](<../en/SunOS/ELF.md> "SunOS/ELF") для SPARC (в разработке)
  * Linux для SPARC



## Поддерживаемые системы для PowerPC

  * Linux для PowerPC
  * [Target Darwin](<../en/Target_Darwin.md> "Target Darwin") (Mac OS X)
  * NetBSD (разработка в основном окончена, но нет поддержки на высоком уровне)
  * [Target MacOS](<../en/Target_MacOS.md> "Target MacOS") (классическая)
  * [MorphOS](<../en/MorphOS.md> "MorphOS") (основные модули реализованы)



## Поддерживаемые системы для PowerPC64

  * Linux (версия 2.1.x и выше)
  * [Target Darwin](<../en/Target_Darwin.md> "Target Darwin") (Mac OS X) (версия 2.3.x и выше)
