# h2pas

Это небольшая утилита командной строки, которая может быть использована для перевода заголовочных файлов языка С в модули языка Pascal. В Free Pascal команда используется для создания модулей, использующих в своей работе важные C библиотеки, такие как GTK или MySQL. 

# fpcmake

Этот инструмент позволяет выполнить компиляцию программ и модулей использующих FPC. В Free Pascal команда используется для создания исполняемых файлов. ( См.: [Fpcmake](<../en/Fpcmake.md> "Fpcmake") ) 

## fpmake

Данный инструмент заменяет собой совместное использование fpcmake и (GNU) make в процессе сборки. Он предназначен для замены fpcmake+make в FPC 2.7.x (См.: [FPMake](<../en/FPMake.md> "FPMake")) 

# ppdep

Это небольшая утилита, которая сканирует программу или модуль и определяет используемые им модули (зависимости), необходимые для компиляции программы или модуля. Она определяет условия для выполнения компиляции и разрешает взаимозависимости модулей друг с другом. 

# delp

Данная программа просматривает папку с программой и определяет ненужные файлы, оставшиеся после компиляции программы, после чего удаляет их. 

# ppudump

Отображает содержимое модуля программы, пригодным для чтения формате. Программа определяет устаревшие версии модулей, а так же не разрешенные зависимости, которые могут негативно сказаться на работе программы. 

# ppufiles

Отображает список всех объектных файлов, которые нужно подключить, что бы использовать модуль. Данный список содержит все библиотеки и модули, необходимые для указанного модуля. 

# ppumove

Объединяет несколько модулей в один, который может быть использован для создания статических и динамических библиотек. 

# ptop

Преобразует исходный код программы для его лучшего чтения и понимания. (См.: [PTop](<../en/PTop.md> "PTop")) 

# rstconv

Данная небольшая утилита преобразует .rst файлы (файлы, содержащие строковые ресурсы, созданные компилятором) в другой формат (в данный момент это - GNU gettext). 

# tply

[TP Lex и Yacc](<../en/Plex_and_Pyacc.md> "Plex and Pyacc") \- программа может быть использована для создания модулей Pascal из Lex лексики и грамматики Yacc. (Автор: Albert Graef) 

# pas2jni

[pas2jni](<../en/pas2jni.md> "pas2jni") \- утилита создания java интерфейса Pascal кода, для его последующего использования в java программах.
