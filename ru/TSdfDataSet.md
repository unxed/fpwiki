# TSdfDataSet

│ **[English (en)](<../en/TSdfDataSet.md> "TSdfDataSet")** │  **[français (fr)](</TSdfDataSet/fr> "TSdfDataSet/fr")** │  **русский (ru)** │    
******TSdfDataSet** [![tsdfdataset.png](https://wiki.freepascal.org/images/3/37/tsdfdataset.png)](</File:tsdfdataset.png>) является компонентом базы данных, который реализует текстовый `[TDataSet](<../en/TDataSet.md> "TDataSet")` в формате [SDF](<../en/SDF.md> "SDF"). 

## Схема

Структура записи берется из: 

  * Свойства схемы, если назначено. Схема - это TStringList, поэтому вы можете использовать, например:


    
    
     
    SDFDataSet1.Schema.CommaText: = '"Field1 = 10", "Field2 = 500"'; // или SDFDataSet1.Schema.Append ('<Field> = <Size>');
    

где `<Field>` \- это FieldName, а `<Size>` \- это размер TStringField, который будет создан. 

  * Первой строки текстового файла, если для свойства `FirstLineAsSchema` установлено значение true
