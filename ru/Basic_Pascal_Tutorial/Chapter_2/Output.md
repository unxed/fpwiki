2B - Output (author: Tao Yue, state: unchanged) 

  
Для записи данных на экран также есть два оператора, один из которых вы уже видели в задании по программированию предыдущей главы: 
    
    
    write (Argument_List);
    writeln (Argument_List);
    

Оператор `writeln` после завершения выполнения переходит на следующую строку. 

Вы можете использовать в списке аргументов строки, константы и литералы. Если вы хотите отобразить внутри строки апостроф, используйте два последовательных апострофа. Для отображения двух последовательных апострофов потребуется использование четырёх апострофов. Такое использование специальной последовательности для указания специального символа называется экранированием, оно позволяет ссылаться на любой символ, даже если для него нет клавиши на клавиатуре.
