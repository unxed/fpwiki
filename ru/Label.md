# Label

│ **[English (en)](<../en/Label.md>)** │  **русский (ru)** │

**Label** \- ключевое слово, использующееся для объявления меток (маркеров для безусловных переходов с помощью ключевого слова [goto](<Goto.md> "Goto/ru")) для дальнейшего использования в модуле/программе.
