## Ночные сборки

[![Warning-icon.png](https://wiki.freepascal.org/images/b/b2/Warning-icon.png)](</File:Warning-icon.png>)

**Предупреждение:** Ночные сборки в настоящее время не предусмотрены. Ссылки в данном разделе являются устаревшими, либо ночные сборки еще могут быть старше текущих версий.  
Эта страница хранится в надежде, что в какой-то момент ночные сборки могут быть восстановлен.

Ночные сборки Lazarus используют последние доступные исходники и последние исправления, а также новые баги. Имеется несколько вариантов ночных сборок Lazarus: 

  * Исходники: Lazarus исправления в zip и bz2
  * Исходники: Lazarus в zip и bz2
  * Установщик win32: Lazarus исправления + fpc 2.4.4 win32
  * Установщик win32: Lazarus + fpc 2.4.4 win32 / win32-arm-wince
  * Установщик win64: Lazarus + fpc 2.4.4 win64
  * Linux исходники rpms: fpc (для создания fpc и rpms fpc-исходники) и lazarus
  * Linux i386 rpms: fpc, fpc-src, lazarus
  * Linux i386 debs tar: fpc, lazarus
  * Linux x86_64 rpms: fpc, fpc-src, lazarus
  * Linux x86_64 debs tar: fpc, lazarus
  * Mac OS X powerpc dmgs: fpc, fpcsrc и lazarus
  * Mac OS X i386 dmgs: fpc, fpcsrc и lazarus



Некоторые зеркала имеют только несколько типов ночных сборок. Посмотрите таблицу ниже. FPC 2.4.5 доступен только с зеркала в Германии. 

[![Warning-icon.png](https://wiki.freepascal.org/images/b/b2/Warning-icon.png)](</File:Warning-icon.png>)

**Предупреждение:** Эти ночные сборки генерируются автоматически и не тестируются. Единственное, что мы можем сказать, в том, что компилятор нашел достаточно хороший исходник для компиляции. Эти ночные сборки предоставляются только для ознакомления. Если исходники содержат ошибки, это может привести к проблемам! Есть риск разрушения ваших файлов проекта, крах вашей машины, и порча вашего диска: такое возможно! (просто помнитеВЫ ИСППОЛЬЗУЕТЕ ПРОГРАММНОЕ ОБЕСПЕЧЕНИЕ, КОТОРОЕ НИКТО НЕ ТЕСТИРОВАЛ)__

## Список изменений ночных сборок

  * 2011.06.28 ночная сборка для релиза fpc.
  * 2006.08.01: ночная сборка дял i386-win32, i386-linux и x86_64-linux собранные с помощью fpc 2.0.4-rc2, чтобы больше людей имели возможность протестировать этот релиз-кандидат.
  * 2006.08.04: ночная сборка powerpc-darwin с помощью fpc 2.0.4-rc2 закачана.
  * 2006.08.13: i386-win32, i386-linux, x86_64-linux и powerpc-darwin ночная сборка выполнена с помощью fpc 2.0.4-rc3
  * 2006.10.02: Установщик win32 получен в двух вариантах: с помощью fpc 2.0.4 и с помощью fpc 2.1.1
  * 2007.06.24: win32 и win64 с использованием исправлений для fpc 2.1.5 с именем 2.1.5-L, смотрите [здесь](</index.php?title=Useful_changes_not_in_the_fixes_branch&action=edit&redlink=1> "Useful changes not in the fixes branch \(page does not exist\)") для подробностей.
  * 2007.07: нет больше исправлений для сборки, все возможные правки внесены в код.
  * 2007.09.20: все fpc 2.0.4 ночные сборки заменены на fpc 2.2.0.
