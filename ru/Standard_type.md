# Standard type

│ [**English (en)**](<../en/Standard_type.md> "Standard type") │  [**italiano (it)**](</Standard_type/it> "Standard type/it") │  **русский (ru)** │    
****

Существуют определенные [типы данных](<Data_type.md> "Data type/ru"), которые являются **стандартными типами данных** в [компиляторе](</index.php?title=Compiler/ru&action=edit&redlink=1> "Compiler/ru \(page does not exist\)") языка [Pascal](<../en/Pascal.md> "Pascal"). Эти типы, как правило, являются _атомарными_ структурами данных, используемыми в [программах](<Program.md> "Program/ru") на языке [Pascal](<../en/Pascal.md> "Pascal") в качестве переменных и констант, которые не могут быть созданы из чего-то другого без этих типов. Обычно стандартные типы данных включают в себя: 

  * [boolean](<Boolean.md> "Boolean/ru") \- значение [true](<True.md> "True/ru") или [false](<False.md> "False/ru")
  * [char](<Char.md> "Char/ru") \- символ
  * [real](<../en/Real.md> "Real") \- числа с десятичной точкой либо представленные в экспоненциальном виде
  * [integer](<Integer.md> "Integer/ru") \- целые числа
  * [set](<Set.md> "Set/ru") \- набор значений



Дополнительные стандартные типы, определенные в большинстве продвинутых компиляторов, включают в себя: 

  * [object](</index.php?title=Object/ru&action=edit&redlink=1> "Object/ru \(page does not exist\)") \- используется для объявления объектов
  * [string](<String.md> "String/ru") \- используется для объявления строк, автоматически обрабатываемых компилятором и [библиотекой времени выполнения](<RTL.md> "RTL/ru").
