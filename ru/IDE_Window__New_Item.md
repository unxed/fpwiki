# IDE Window: New Item

│ **[English (en)](<../en/IDE_Window__New_Item.md>)** │  **русский (ru)** │

Диалог **File|New item** помогает начать новый элемент. Элементы, показанные в этом диалоговом окне, можно расширить, установив пакеты Lazarus.
