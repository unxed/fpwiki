## Важно

Вы должны [настроить отладчик](<../en/Debugger_Setup.md> "Debugger Setup") и запустить проект для отладки. Только после этого данное окно будет полезно. 

## Обзор

[![Debug output.png](https://wiki.freepascal.org/images/6/62/Debug_output.png)](</File:Debug_output.png>)

В этом окне отображаются команды и ответы между IDE и отладчиком. 

Для обычного процесса отладки в этом окне нет необходимости. Оно может предоставлять полезную информацию, если сам отладчик не работает должным образом.
