# Scientific publications

│ **[English (en)](<../en/Scientific_publications.md>)** │  **русский (ru)** │

Благодаря совместимости с богатой традицией алгоритмов, написанных на Паскале, быстрому созданию собственного кода и широкой межплатформенной доступности, Free Pascal является идеальной основой для научных приложений. Это может быть основной причиной, по которой множество исследовательских проектов используют Lazarus и FPC. 

[![Papers banner.png](https://wiki.freepascal.org/images/3/3e/Papers_banner.png)](</File:Papers_banner.png>)

Это (вероятно, всегда неполный) список исследовательских работ, рефератов, отчетов и других научных публикаций о проектах, в которых использовались Lazarus, Free Pascal или Pascal Script для вычислительной науки. Представленная здесь коллекция ограничена публикациями на русском языке. Версии этой статьи на других языках в первую очередь предназначены для публикации в соответствующем регионе.
