# Packages Base

│ **[English (en)](<../en/Packages_Base.md>)** │  **русский (ru)** │

Обратите внимание, что начиная с версии 2.2.2, больше не будут доступны основные и дополнительные пакеты, потому что все они были объединены в packages/subdir. 

Новый список пакетов смотрите [здесь](<../en/Package_List.md> "Package List"). 

  


  * [netdb](<../en/Netdb.md> "Netdb") \- разрешение DNS имён
  * [Regexpr](<../en/Regexpr.md> "Regexpr") \- Regex engine
  * [PascalMagick](<../en/PascalMagick.md> "PascalMagick") \- заголовки PascalMagick для pascal.
  * [FPC and Apache Modules](<../en/FPC_and_Apache_Modules.md> "FPC and Apache Modules") \- перевод заголовков Apache в разрабатываемые модули.
  * [FPC and DBus](<../en/FPC_and_DBus.md> "FPC and DBus") \- заголовки для dbus, межпроцессорной библиотеки.
