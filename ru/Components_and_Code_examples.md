## Компоненты из Lazarus-CCR

### Мультимедиа

  * [ ACS (Audio Component Suite)](<../en/ACS.md> "ACS") \- коллекция компонентов для разработки приложений, работающих с аудио-данными (воспроизведение/запись/обработка). Может воспроизводить wav, ogg, mp3, mp2, wma и другие форматы, записывать звук с любого источника, "грабить" и много другое. См. [ACS](<http://acs.ullihome.de/>).
  * [Bluetooth](<../en/Bluetooth.md> "Bluetooth") \- доступ к Bluetooth-устройствам (например, Wiimote).



### Графика

  * [GLScene](<../en/GLScene.md> "GLScene") \- полноценная библиотека 3D-графики, использующая для рендеринга OpenGL. Позволяет редактировать 3D-сцены непосредственно из IDE. См. также [официальный сайт](<http://www.glscene.org>) GLScene.
  * [TOpenGLBox](<../en/TOpenGLBox.md> "TOpenGLBox") \- каркасный OpenGL-компонент для Lazarus, реализующий область рендеринга OpenGL.
  * [SMNetGradient](<../en/SMNetGradient.md> "SMNetGradient") \- градиентная заливка для Lazarus.
  * [TAChart](<../en/TAChart.md> "TAChart") \- удобные и функциональные диаграммы для Lazarus.
  * [PlotPanel](<../en/PlotPanel.md> "PlotPanel") \- компоненты для отрисовки диаграмм и графиков.
  * [LazRGBGraphics](<../en/LazRGBGraphics.md> "LazRGBGraphics") \- пакет для быстрой обработки изображений и манипуляции пикселями (такими как scan line) в памяти.
  * [TMetafile/TMetafileCanvas](<../en/TMetafile_/_TMetafileCanvas.md> "TMetafile / TMetafileCanvas") \- реализация EnhMetafile API для Windows.
  * [ZenGL](<../en/ZenGL.md> "ZenGL") \- кросс-платформенная библиотека для разработки игр, использующая OpenGL.
  * [BGRABitmap](<../en/BGRABitmap.md> "BGRABitmap") \- отрисовка фигур и изображений с прозрачностью, прямым доступом к пикселям и др.
  * [Double Gradient](<../en/Double_Gradient.md> "Double Gradient") \- компонент для простой отрисовки 'двойного градиента' и 'n-градиента'.
  * [Gradient Filler](<../en/Gradient_Filler.md> "Gradient Filler") одно из лучших решений для создания произвольных n-градиентов в Lazarus.
  * [PascalMagick](<../en/PascalMagick.md> "PascalMagick") \- простой в использовании API для взаимодействия с [ImageMagick](<http://www.imagemagick.org>), а также кросс-платформенное ПО для создания, редактирования и компоновки пиксельных (bitmap) изображений.



### Инструменты

  * [FpSystools](<../en/FpSystools.md> "FpSystools") \- адаптация Kylix-пакета TurboPower Systools для Lazarus/FPC.
  * [DCPcrypt](<../en/DCPcrypt.md> "DCPcrypt") \- библиотека криптографических компонентов DCPcrypt.
  * [RXfpc](<RXfpc.md> "RXfpc/ru") \- некоторые из компонентов RXlib, конвертированные на Lazarus.
  * [MultiLog](<../en/MultiLog.md> "MultiLog") \- система ведения логов, разработанная для FPC-Lazarus.
  * [OnGuard](<../en/OnGuard.md> "OnGuard") \- порт Turbo Power OnGuard
  * [UniqueInstance](<../en/UniqueInstance.md> "UniqueInstance") \- компонент, блокирующий запуск более чем одной копии приложения.
  * [XDev Toolkit](<../en/XDev_Toolkit.md> "XDev Toolkit") \- кросс-платформенный пакет инструментов для разработчиков.
  * [MouseAndKeyInput](<../en/MouseAndKeyInput.md> "MouseAndKeyInput") \- юнит для платформо-независимого управления вводом посредством мыши и клавиш.
  * [PascalSane](<../en/PascalSane.md> "PascalSane") \- бинд API для сканера (libsane) с примером использования.
  * [log4delphi](<../en/log4delphi.md> "log4delphi") \- система ведения логов, основанная на log4j.
  * [fppkggui](<../en/fppkggui.md> "fppkggui") \- простой gui для [fppkg](<../en/fppkg.md> "fppkg").
  * [SymScan](<../en/SymScan.md> "SymScan") \- интерфейс сканера штрих-кодов для устройств серий Symbol/Motorolla MC.
  * [Theodp](<../en/UTF8_Tools.md> "UTF8 Tools") \- инструменты для работы с UTF-8.
  * [Delphi form to HTML converter](<../en/Delphi_form_to_HTML_converter.md> "Delphi form to HTML converter") \- Lazarus-версия компонента Delphi Form to HTML (F2H).



### Архивация

  * [Zlibar](<../en/Zlibar.md> "Zlibar") \- объекты для создания и распаковки архивов zlib, содержащих несколько файлов.
  * [FreePascalArchivePackage](<../en/FreePascalArchivePackage.md> "FreePascalArchivePackage") \- адаптация библиотеки TurboPower Software Abbrevia для Free Pascal Compiler.
  * [ZipFile](<../en/ZipFile.md> "ZipFile") \- компонент для инкапсуляции zip-файлов (с архивом можно работать как с обычной файловой системой).
  * [libtar](<../en/libtar.md> "libtar") \- класс для работы с .TAR-архивами от Stefan Heymann; может использоваться совместно с zstream для создания файлов .tar.gz.
  * [bzip2lib](<../en/bzip2lib.md> "bzip2lib") \- потоковые классы для сжатия и распаковки bzip2.
  * [paszlib](<../en/paszlib.md> "paszlib") \- преобразованая стандартная библиотека Zlib для Pascal (без зависимостей).



### Редактирование и просмотр

  * [PowerPDF](<../en/PowerPDF.md> "PowerPDF") \- порт визуальных компонентов PowerPDF для Lazarus.
  * [RichView](<../en/RichView.md> "RichView") \- порт freeware-редакции компонента TRichView для Lazarus.
  * [RichMemo](<RichMemo.md> "RichMemo/ru") \- кросс-платформенная реализация редактора и просмотрщика Rich Text.
  * [SynEdit](<../en/SynEdit.md> "SynEdit") \- компоненты типа TMemo с подсветкой синтаксиса и другими функциями (используются IDE).
  * [THtmlPort](<../en/THtmlPort.md> "THtmlPort") \- порт компонентов HTML Components (THtmlViewer, TFrameViewer, TFrameBrowser) от Dave Baldwin для Lazarus.
  * [GeckoPort](<../en/GeckoPort.md> "GeckoPort") \- порт Gecko SDK for Delphi от Takanori Ito для Lazarus, включающий TGeckoBrowser.
  * [Fshcomp](<../en/Fshcomp.md> "Fshcomp") \- компоненты Edit.



### Сети

  * [BeepFp](<../en/BeepFp.md> "BeepFp") \- framework для протокола BEEP.
  * [Sockets](<../en/Sockets.md> "Sockets") \- компоненты для работы с сокетами TCP/IP.
  * [lNet](<../en/lNet.md> "lNet") \- набор компонентов, обеспечивающих простую, однопотоковую управляемую событиями реализацию протоколов, начиная с TCP и UDP, и заканчивая SMTP и HTTP. lNet не использует никаких внешних библиотек и очень легко портируется на новые платформы.
  * [FPC and Apache Modules](<../en/FPC_and_Apache_Modules.md> "FPC and Apache Modules") \- заголовочные файлы для создания модулей к Apache на FPC.
  * [Web Services Toolkit](<../en/Web_Service_Toolkit.md> "Web Service Toolkit") \- пакет для работы с веб-сервисами.



### Базы данных

  * [fb embedded2 Laz](<../en/fb_embedded2_Laz.md> "fb embedded2 Laz") \- использование встраиваемой (embedded) версии FireBird 3 в Lazarus.
  * [TPSQL](<../en/TPSQL.md> "TPSQL") \- компоненты для подключения к базам данных PostgreSQL.
  * [tiOPF](<../en/tiOPF.md> "tiOPF") \- TechInsite Object Persistent Framework (версия 2).
  * [TParadoxDataSet](<../en/TParadoxDataSet.md> "TParadoxDataSet") \- реализация TDataSet, позволяющая читать файлы Paradox до версии 7 (возможно и выше).
  * [ZeosDBO](<../en/ZeosDBO.md> "ZeosDBO") \- набор компонентов для работы с различными базами данных (Firebird, PostgreSQL, MySQL, Oracle, SQLite и другие).
  * [SQLitePass](<../en/SQLitePass.md> "SQLitePass") \- компоненты для подключения к базам SQLite.
  * [MS Access](<../en/MS_Access.md> "MS Access") \- работа с использованием TODBCConnection через FILEDSN



### Форматы файлов

  * [CsvDocument](<CsvDocument.md> "CsvDocument/ru") \- работа с CSV файлами с использованием парсера или "клеточного" интерфейса наподобие того, что используется в компоненте StringGrid.



### Контейнеры

  * [StringHashMap](<../en/StringHashMap.md> "StringHashMap") \- контейнер String -> Pointer. Быстрый и расходующий минимум памяти.



### Система

  * [EpikTimer](<../en/EpikTimer.md> "EpikTimer") \- точный таймер, написанный специально для Lazarus.
  * [Manager Worker Threads System](<../en/Manager_Worker_Threads_System.md> "Manager Worker Threads System") \- менеджер потоков, позволяющий обрабатывать многочисленные объекты и данные в реальном времени.
  * [TrayIcon](<../en/TrayIcon.md> "TrayIcon") \- кросс-платформенный компонент для создания значка приложения в системном трее.
  * [TPopupNotifier](<../en/TPopupNotifier.md> "TPopupNotifier") \- компонент, показывающий подсказки в виде облака (balloon).
  * [MultiDoc](<../en/MultiDoc.md> "MultiDoc") \- компонент для написания псевдо-MDI приложений в Lazarus.
  * [MDButtonsBar](<../en/MDButtonsBar.md> "MDButtonsBar") \- ButtonsBar для компонента MultiDoc.
  * [MPICH](<../en/MPICH.md> "MPICH") \- биндинги для MPI (Message Passing Interface).
  * [Bluetooth](<../en/Bluetooth.md> "Bluetooth") \- доступ к Bluetooth-устройствам.



### Визуальные компоненты

  * [VirtualTreeview](<../en/VirtualTreeview.md> "VirtualTreeview") \- порт быстрого компонента virtual treeview от [SoftGems](<http://www.soft-gems.net/index.php?option=com_content&task=view&id=12&Itemid=33>).
  * [Turbopower Visual PlanIt](<../en/Turbopower_Visual_PlanIt.md> "Turbopower Visual PlanIt") \- порт компонентов для планирования Visual PlanIt для Lazarus.
  * [RingChart and AnalogWatch](<../en/RingChart_and_AnalogWatch.md> "RingChart and AnalogWatch") \- ещё одна эллиптическая диаграмма, а также аналоговые часы для Lazarus и FPC.
  * [ColorBox](<../en/ColorBox.md> "ColorBox") \- "пипетка" (сolor-picker) с предварительным просмотром.
  * [Spook's Panel Components](<../en/Spook's_Panel_Components.md> "Spook's Panel Components") \- коллекция компонентов-панелей.
  * [HistoryFiles](<../en/HistoryFiles.md> "HistoryFiles") \- компонент для хранения списка "последних файлов" в .ini-файле и отображения его в меню.
  * [ColorPalette](<../en/ColorPalette.md> "ColorPalette") \- цветовая палитра, позволяющая использовать произвольные наборы цветов.
  * [OrphPort](<../en/OrphPort.md> "OrphPort") \- реализация контролов TurboPower Orpheus для Lazarus.
  * [TSubForm](<../en/TSubForm.md> "TSubForm") \- Data-Aware компоненты SubForm, основанные на записях и датасетах (dataset).
  * [Lui Controls](<../en/Lui_Controls.md> "Lui Controls") \- набор визуальных компонентов (TToggleLabel, TMenuButton).
  * [JvXPBar](<../en/JvXPBar.md> "JvXPBar") \- порт контрола TJvXPBar из состава [JVCL's](<http://jvcl.sourceforge.net>), отображающего иконку, заголовок и ноль или более кликабельных объектов в своей клиентской области.
  * [CmdLine](<../en/CmdLine.md> "CmdLine") \- строка запроса команды.
  * [Wile64](<../en/Wile64.md> "Wile64") \- набор компонентов для Lazarus (TGifAnim, TColorProgress, TLabelCut и другие).
  * [TGradButton](<../en/TGradButton.md> "TGradButton") \- кнопка с улучшенным внешним видом.
  * [TMyRollOut and ExpandPanel](<../en/TMyRollOut_and_ExpandPanel.md> "TMyRollOut and ExpandPanel") \- сворачивающиеся блоки (аналог TJvRollOut); могут быть размещены на скрывающейся панели.
  * [FileMenuHandler](<../en/FileMenuHandler.md> "FileMenuHandler") \- сохранение списка "последних файлов" и реализация команд "Открыть", "Сохранить", "Сохранить как" и "Выход".
  * [ZVDateTimeControls Package](<../en/ZVDateTimeControls_Package.md> "ZVDateTimeControls Package") \- пакет, включающий TZVDateTimePicker (клон TDateTimePicker из Delphi) и TDBZVDatePicker (data-aware версия TZVDateTimePicker).
  * [BGRAControls](<../en/BGRAControls.md> "BGRAControls") \- набор компонентов, основанных на пакете [BGRABitmap](<../en/BGRABitmap.md> "BGRABitmap") (включает BGRAImageList, BGRASpeedButton, BGRAButton и BGRAPanel).

## Пакеты для FPC/Lazarus, размещённые на сайтах разработчиков

#### Архивация

  * [lazarus-zlib](<http://code.google.com/p/lazarus-zlib/>) \- простой в использовании класс-обёртка для zlib.



#### Графика и игры

  * [Graphics32](<http://graphics32.org>) \- набор компонент для работы с графикой. Включает более функциональную реализацию TImage (TImage32).
  * [Castle Game Engine](<../en/Castle_Game_Engine.md> "Castle Game Engine") \- движок 3D-игры, ориентированный прежде всего на форматы VRML/X3D.
  * [Diagram](<http://www.benibela.de/sources_de.html#diagram>) \- модуль для отрисовки диаграмм с использованием системы моделей/просмотров.
  * [DrawObjectsExtended](<http://www.tcoq.org/composants>) \- графический компонент для отрисовки структурных диаграмм, портированный из Delphi.
  * [mpg123.dll](<http://www.breakoutbox.de/pascal/pascal.html#mpg123>) \- кросс-платформенный декодер форматов MPEG layers 1, 2 и 3 (MP3 протестирован плохо); прилагаемый пример содержит два враппера, протестированных только под Win32.
  * [FreeImage](<http://breakoutbox.de/pascal/applications.html>) \- открытая библиотека, обеспечивающая поддержку популярных графических форматов, таких как PNG, BMP, JPEG, TIFF и др. (работает в Windows, Linux и Mac OS X). Включает PicViewer - пример приложения (только для Windows), показывающего изображения с использованием данной библиотеки (DLL).



#### Мультимедиа

  * [PortAudio](<http://www.breakoutbox.de/pascal/pascal.html#PortAudio>) \- проект кросс-платформенного Audio API, доступный для Windows, Mac OS X, Unix (OSS/ALSA), SGI и BeOS. Содержит врапперы, позволяющие работать с C-библиотеками, а также примеры использования PortAudio DLL в Lazarus LCL под Windows. Враппер для portaudio.dll взят из Sourceforge-проекта UltraStar.
  * [UltraStar Deluxe](<http://sourceforge.net/projects/ultrastardx/>) \- заголовочные файлы к различным библиотекам для Windows, Linux и Mac OS X (с некоторыми сокращениями): portaudio, BASS, ffmpeg, SDL, libpng, FreeImage, freetype, JEDI-SDL, Lua, midi, pcre, portmixer, projectM, samplerate, SQLite, zlib, fft.
  * [RackCtls](<../en/RackCtls.md> "RackCtls") \- коллекция компонентов для работы с "Hi-fi-системами".



#### Графика и интерфейс

  * [HTML Viewer Components](<http://code.google.com/p/thtmlviewer/>) \- ещё одна попытка реанимировать HTMLView от Dave Baldwin. Заявлена совместимость с Delphi и Lazarus, но поддержка Lazarus находится в стадии alfa-тестирования.
  * [TTreeListView](<http://www.benibela.de/components_en.html#treelistview>) \- комбинация TTreeView и TListView, отображающая ветви дерева с дополнительными колонками.
  * [ExcelInterfaces](<http://www.tcoq.org/composants>) \- компонент для работы с таблицами Excel из программ на FPC и Lazarus. Он также демонстрирует использование интерфейсов COM на платформе Windows.
  * [TMapViewer](<http://keit.co/mapviewer.zip>) \- компонент для работы с популярными картографическими сервисами Google Maps и OpenStreet. Использует только стандартные графические контролы. Есть версия для Windows (только стандартные средства) и Linux (требуется библотека Synapse).



#### Сеть и устройства

  * [PascalSCADA](<http://wiki.lazarus.freepascal.org/PascalSCADA>) \- набор компонентов для упрощения разработки приложений HMI/SCADA, взаимодействующих с PLC или другими промышленными устройствами.
  * [ICU4PAS](<http://www.icu4pas.org/>) \- кросс-платформенные классы на Object Pascal для Direct Class Wrapper с использованием библиотек ICU.
  * [Internet Tools](<http://www.benibela.de/sources_de.html#internettools>) \- класс для получения и парсинга html-страниц, а также автообновления.
  * [CUPS for Lazarus project](<http://cups4lazarus.sourceforge.net/>) \- реализация Common UNIX Printing System для FPC/Lazarus.
  * [Runge-Kutta](<http://tcoq.free.fr/composants.html>) \- научный компонент для интегрирования дифференциальных уравнений с использованием событий.
  * [Brain Patchwork DX, LLC.](<http://www.bpdx.com/>) \- порт визуальной и невизуальной реализации клиента и сервера TCP/UDP для Lazarus 0.9.22/FPC 2.0.4.
  * [Synapse](<http://www.ararat.cz/synapse/>) \- библиотека для работы с протоколом TCP/IP.
  * Indy 
    * [Indy for Lazarus project](<http://indy4lazarus.sourceforge.net/>) \- 119 компонентов Indy для for FPC/Lazarus (проект заморожен).
